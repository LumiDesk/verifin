# AGENTS.md — Agent Notes

这些笔记是**决策记录**，不是权威事实。判断“现在是什么”看源码、`docs/` 与 `AGENTS.md`；
只有想知道“为什么这么定、否掉了什么”时才读这里。

- 新写一份笔记：按 [README.md](README.md) 的格式，放进 `proposed/`。
- 实现后：移到 `implemented/`，只补事实同步（路径、类名、默认值），不改当初的决策。
- 否掉的方案：移到 `rejected/`，或直接删掉——只在它能防住某个诱人的错误时才留。
- **不要把 `implemented/` 当成规范**：规范在 `docs/` 和 `AGENTS.md`，这里只是来龙去脉。
- 不在笔记里写待办清单、进度、人名；那些属于 issue。
