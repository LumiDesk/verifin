# Veri Fin v1.18.16 手机验收清单

版本：`v1.18.16`（Android arm64 GitHub 自分发预发布）

安装时直接覆盖现有 v1.18.15，**不要卸载应用、不要清除数据**。本版本主要是备份安全边界、通知失败反馈、弹窗统一和触控区域调整；账目口径、首页结构、资产/看板/交易主流程没有刻意改变。

## 一、安装与基础回归

- [ ] 从 GitHub 预发布下载 arm64 APK，覆盖安装后版本号显示为 `v1.18.16`。
- [ ] 原有账本、账户、交易、预算、主题、语言和设置仍然存在。
- [ ] 冷启动、从后台返回、锁屏后返回均能进入原来的页面。
- [ ] 浅色/深色主题各检查一次；中文/English 各检查一次。
- [ ] 360dp 窄屏或小字体设备上没有明显横向溢出、底部按钮被遮挡或弹窗无法滚动。

## 二、数据管理与备份

### 本地备份

- [ ] 「我的 → 数据管理」选择备份目录，执行一次未加密手动备份。
- [ ] 确认备份文件仍能从目录恢复，正常 ZIP 导入不受影响。
- [ ] 执行一次加密备份，输入正确口令可以恢复。
- [ ] 使用错误口令时仍显示明确失败，不会替换当前数据。

### WebDAV 恢复

- [ ] 配置 WebDAV 后测试连接、上传一个备份、列出远端文件并恢复。
- [ ] 远端返回超过限制的文件时，应用应快速提示文件过大并保持当前账目不变。
- [ ] 远端文件列表异常过大时，应用应提示读取失败，不应卡死或崩溃。
- [ ] 自动上传开启时，检查正常成功后“上次备份时间”会更新。
- [ ] 模拟一个目标失败（例如暂时断开 WebDAV）：即使另一个目标成功，“上次备份时间”也不应冒充所有目标都已完成；恢复网络后下一次自动备份应重试。

### 异常备份文件

- [ ] 导入超过条目数量限制的 ZIP，提示压缩包条目过多，不清空当前数据。
- [ ] 导入声明解压体积过大的 ZIP，提示解压后过大，不崩溃。
- [ ] 导入篡改 KDF 迭代数、salt、nonce 或 MAC 长度的加密 JSON，提示格式/参数无效，不长时间占满 CPU。

## 三、通知提醒

页面：`我的 → 设置 → 记账提醒`

- [ ] 首次开启时能正常申请通知权限；拒绝权限时显示权限被拒提示，不显示保存成功以外的误导文案。
- [ ] 已授权时点击「发送测试通知」，通知栏能收到测试通知，并显示成功反馈。
- [ ] 模拟系统拒绝/通知渠道异常时，点击测试通知显示失败反馈，不显示“已发送”。
- [ ] 开启每日提醒并设置未来 2–3 分钟的时间，锁屏等待能收到提醒（需要真机）。
- [ ] 关闭提醒并保存后，不再收到下一次计划提醒。

## 四、统一弹窗外观与交互

以下入口都改为统一的实色表面、顶部圆角、拖拽把手和安全区处理。逐项打开、关闭、拖拽和系统返回：

- [ ] 账户图标选择：`资产 → 添加/编辑账户 → 图标`。
- [ ] AI 记账入口：首页记账按钮长按/AI 模式。
- [ ] 应用锁方式选择：`我的 → 设置 → 应用锁 → 锁定方式`。
- [ ] WebDAV 恢复文件选择：`我的 → 数据管理 → 从 WebDAV 恢复`。
- [ ] 第三方账单来源选择：`我的 → 数据管理 → 导入账单`。
- [ ] 首页指标选择：首页相关设置中的走势指标槽位。
- [ ] 导入预览中的账户映射、分类映射、标签映射弹窗。
- [ ] 退款新增/编辑弹窗：交易详情 → 退款。
- [ ] 统计分析分类详情弹窗：`看板 → 统计分析 → 分类行`。

每个弹窗检查：

- [ ] 顶部把手只出现一次，内容不会被把手遮挡。
- [ ] 顶部圆角、背景色和页面其他弹窗一致，没有透明/玻璃/模糊层。
- [ ] 矮屏或键盘出现时内容可以滚动，保存按钮和最后一项可达。
- [ ] 点击外部、系统返回和取消都不会误保存草稿。

## 五、触控区域与页面细节

- [ ] 交易列表筛选胶囊容易点中，点击范围明显不止文字本身。
- [ ] 分类、标签、账户分区标题旁的操作按钮容易点中，不需要精确点击 32dp 小图标。
- [ ] 首页、资产、看板、交易列表底部悬浮按钮不遮挡最后一条内容。
- [ ] 大字号下 Header、副标题、筛选胶囊和弹窗按钮仍能完整阅读。

## 六、核心页面不变性回归

- [ ] 首页：快速记账、预算卡、日历、趋势、最近交易均可打开；记一笔保存后余额和首页摘要同步。
- [ ] 资产：账户类型/分组视图、展开折叠、账户详情、信用卡额度和还款入口正常。
- [ ] 看板：预算执行、收入/支出摘要、分类环、排行、日趋势、月趋势和面板设置正常。
- [ ] 交易：搜索、时间筛选、账户/分类/标签筛选、多选批量操作和待退款入口正常。
- [ ] 预算：预算总览、默认预算、单期覆盖、自定义周期和趋势正常。
- [ ] 我的：账本切换、设置、数据管理、AI 设置、应用锁、提醒和日志入口正常。
