# Android 视觉稳定性记录（历史）

本文记录 2026-09-05 至 2026-09-10 的 Android 视觉排查，**不代表当前材质实现**。

当时曾排查滚动变黑、页面闪烁、预测性返回透出、导航动画和字体过大等问题。后续实现已经移除玻璃材质、背景模糊、折射透镜和全局渐变，页面改用不透明实色；导航也改为当前的停靠式 `VeriBottomBar`。

当前视觉规则和验收标准以 [统一设计规范](../design-system.md) 和 [Android 开发说明](android-development.md) 为准。历史排查中关于 `VeriGlassSurface`、Shader、两档材质和背景过滤的描述不能作为新代码依据。
