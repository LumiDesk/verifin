# Android 玻璃动态画面与字体回归（2026-09-05）

v1.16.2 真机反馈：滚动变黑、进入页面闪烁、预测性返回半途页面互相透出、
最近交易标题按压横条、导航切换闪烁、资产等页面字体偏大。

## 代码证据与本轮候选修复

- 原背景只位于 MaterialApp.builder 的 Navigator 外；玻璃 Scaffold 透明，
  colorScheme.surface 也被设置成低透明染色。转场中的页面没有自己的完整背景。
  现在 `VeriPageTransitionsBuilder` 在系统预测性转场内部包裹每个路由自己的
  `VeriGlassBackdrop`，背景与页面同尺寸、同变换；全局 Material surface 恢复不透明。
- 玻璃列表关闭越界拉伸，避免拉伸产生的独立合成缓冲丢失背景输入；
  `VeriGlassSurface` 的背景过滤改为 src 混合。仍保留真实背景模糊及两档材质。
- 最近交易标题以前仅关闭 hover，highlight/splash 仍走默认值；现三者均透明，点击与焦点保留。
- 导航以前 `toImageSync` 返回后立即把纹理作为可绘制内容。现在等待 `toImage` 完成，
  校验本次手势 generation、源 revision 和尺寸；过期结果释放，松手显示实时图标。
- `a37540e` 为候选设计全局放大 display/title/label 字号，v1.16 发布启用候选参数后
  同时影响资产、设置、管理页等；本机系统 font_scale 为 1.0。恢复 v1.15.17 的全局
  字号和页面标题 w800，保留首页主金额 32sp、导航 12sp 等局部规则，字体家族不变。

## 后续反馈：首启、Tab 中点、输入、菜单与预算环

用户确认字体恢复正常；继续反馈同意协议后首页露出、Tab 中点高亮闪烁、输入白边、菜单过黑，
并要求恢复原预算环。本轮对上一轮候选方案作以下替换：

- `OnboardingGate` 位于隐私门卫和应用锁内，完成引导前不构建 Shell；删除 Shell 首帧后 push 引导。
  新增逐帧断言，确认同意后的 12 帧中没有 HomePage；没有清除用户数据或修改备份格式。
- 闪烁的直接路径是 selectedIndex 跨中点改变 revision，旧快照失效后临时退出折射，再在读回完成后恢复。
  异步等待只解决纹理就绪，不能解决这种模式切换。正式导航现在完全移除 toImage 和 revision 机制，
  使用 [ImageFilter.shader / ImageFiltered](https://docs.flutter.dev/ui/design/graphics/fragment-shaders)
  对当前帧导航进行过滤；前两个尺寸 uniform 与第一个 sampler 由引擎设置，并处理 GLES 的 Y 翻转。
  不支持该 API 的后端不调用它，保留实时内容与形变。静止关闭过滤，高亮变化不重建过滤子树。
- 过滤输入固定完整透明边界，避免包围盒随字形变化；透镜边缘位移平滑回到原坐标，避免字形切痕。
- 输入默认无边框，聚焦蓝边、错误红边；菜单遮罩降为 12%，提亮中性灰基色后使用 72% 染色，取消整块菜单的 Opacity。
  弹层染色之内增加透明 Material，修复 ListTile 反馈被 DecoratedBox 遮住的断言。
- 预算环删除玻璃分支与参数，恢复常规 SweepGradient，与预算详情保持一致。
