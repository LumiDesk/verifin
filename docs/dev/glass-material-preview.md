# 玻璃材质预览（历史记录）

本文记录 2026-09-05 的实验，**不代表当前实现，也不是开发指南**。

2026-09-10 用户确认玻璃方向是设计败笔，项目删除了磨砂玻璃、方向高光、导航折射透镜、Shader 和全局背景渐变。相关源码、开关和测试入口均已移除；当前卡片、导航、菜单、弹层和页面背景使用不透明实色。

保留本文的原因只有两个：

- 解释为什么当前实现不再恢复 `BackdropFilter` 或导航透镜；
- 指向当时的 Android 图形问题调查，便于理解历史崩溃背景。

当前规则见 [统一设计规范](../design-system.md)，Android 验收见 [Android 开发说明](android-development.md)。
