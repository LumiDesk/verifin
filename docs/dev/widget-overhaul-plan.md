# 桌面小组件重构方案

状态：产品规格 v3（2026-09-13）

## 产品模型

小组件分为两层：固定模板和桌面实例。应用内只展示固定模板，不保存用户设计；桌面 `appWidgetId` 各自保存模板、账本、指标、图表和背景配置。配置只存在设备原生小组件存储中，不进入备份或导出；小组件被桌面销毁时同步清理配置。

## 尺寸与模板

支持 1×2、2×2、2×4 三种预览尺寸，名称按「行 × 列」解释：1×2 横向、2×2 正方形、2×4 横向宽卡。旧版试验尺寸读取时映射到这三类，编辑页不再提供旧尺寸。Android 启动器可调整实际尺寸。

- 1×2：主指标和一个快速记账入口或辅助值。
- 2×2：主指标加两个辅助指标，或主指标加预算进度环。
- 2×4：左侧主指标和辅助指标，右侧图表或预算进度。

首批固定模板：快速记账（1×2）、预算进度（2×2）、净资产（2×2）、收支趋势（2×4）。系统选择器按模板展示四个固定入口，不提供自由缩放；模板本身不由用户在应用内编辑。

## 设计配置

每个用户设计包含：稳定 UUID、名称、模板、默认尺寸、主指标、按顺序排列的辅助指标、图表类型/序列/日期范围/粒度、账本范围、账户/分类/标签筛选、点击动作、金额隐私显示、背景配置和更新时间。

指标首批覆盖今日/周期收支、预算剩余与使用率、结余、净资产、资产/负债、账户余额、交易笔数和储蓄率。图表只表达一个问题：收支趋势、预算消耗、净资产变化或账户余额变化。

## 背景与视觉

背景支持内置主题、纯色和本地相册图片。用户图片支持裁切焦点和明暗遮罩；图片作为不透明表面使用，不引入玻璃、模糊或折射效果。文字、图表和状态必须满足对比度要求，图片失败时回退到纯色主题。

组件遵循“大数字 + 小指标 + 一个视觉重点”的层级。缺率、超支、过期和隐藏金额必须有文字状态，不能只靠颜色表达。

## 用户流程

“我的 → 桌面小组件”是固定模板展示页，使用瀑布流展示不同模板和尺寸；页面只读，不提供保存、编辑、删除、长按移动或排序。

画布按组件尺寸使用自适应瀑布流布局：窄屏两列，宽组件跨两列；组件本身就是预览，不再进入编辑态。

旧版用户设计的编辑态、长按删除和拖动排序已废弃。应用内画布只读；编辑、删除和排序由 Android 桌面管理当前实例。

桌面流程：长按桌面空白处 → 小组件 → 选择 VeriFin 模板 → 放置 → 在原生配置页选择账本、指标、图表范围、背景和点击动作 → 保存返回桌面。长按桌面上的小组件可再次进入同一配置页。

Android 系统选择器展示四个固定模板 Provider，均使用同一个原生配置 Activity；配置通过 `appWidgetId` 隔离。原生快照按账本同步，Provider 只读取当前实例配置和对应账本数据。旧的用户设计 Provider 停用并不再参与选择器。

## 导出与导入

小组件配置不属于备份范围。备份与导出只包含账本数据及既有应用设置，不包含模板实例、`appWidgetId`、背景资源或桌面排序。

导入不会创建或修改桌面小组件实例；恢复账本后，已有实例在下一次刷新时按其设备本地账本配置读取数据。

清除本地数据时同时清除设计和设备绑定；设计配置不包含密钥、口令、WebDAV 凭证、AI 凭证或聊天历史。

## 刷新与点击

当前实现：应用按账本同步原生指标快照；每个桌面实例通过 `appWidgetId` 读取自己的模板、账本、指标、图表范围和背景配置。Provider 的 `RemoteViews` 只负责渲染，配置 Activity 负责保存并刷新实例。系统格子的实际宽高由启动器决定，应用内预览只作为模板展示。

以下仍是完整方向：用户设计跨日自动重算、图表点击携带全部筛选、记账预填账户和分类，尚不能以已实现验收。

交易、退款、预算、汇率、账户和账本变化后刷新相关设计的所有实例；跨日和跨预算周期重新计算，失败时保留可解释的旧数据并显示刷新状态。

整卡点击使用设计主动作；图表区域进入带相同账本、日期范围和筛选的统计页；快速记账按钮预填设计指定的账本、类型、账户和分类。

## 开发阶段

1. 固定模板展示页使用瀑布流展示四种模板与三种尺寸。
2. 四个 Android Provider 使用统一配置 Activity，设置按 `appWidgetId` 保存。
3. 同步各账本指标快照，实例按所选账本渲染并支持删除清理。
4. 完成系统选择器、添加、长按编辑、浅深色、大字体和不同启动器验收。

本方案不改变交易、预算、退款和多币种计算口径；小组件只读取这些领域已有的权威结果。
