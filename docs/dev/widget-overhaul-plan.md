# 桌面小组件重构方案

状态：产品规格 v2（2026-09-12）

## 产品模型

小组件分为三层：基础模板、我的小组件设计、桌面实例。基础模板只提供布局，不直接添加到桌面；用户先创建并保存设计，再从“我的小组件”添加。一个设计可以绑定多个桌面实例，编辑设计后所有实例同步更新。

设计定义是可迁移的用户数据，桌面 `appWidgetId` 只是设备本地绑定，不进入备份。删除仍被桌面使用的设计时，先提示解绑，不能留下空白组件。

## 尺寸与模板

支持 1×1、2×2、4×1、4×2、2×4 五种预览尺寸。Android 启动器可调整实际尺寸，运行时按 options 选择最接近的布局变体。

- 1×1：一个主指标或快速记账按钮。
- 2×2：主指标加两个辅助指标，或主指标加预算进度环。
- 4×1：三个并列指标加一个快速记账入口。
- 4×2：主指标、两个辅助指标和一张趋势图。
- 2×4：主指标加纵向图表、分类排行或账户列表。

首批基础模板：快速记账、预算进度、收支趋势、净资产。每个尺寸限制可用插槽数量，避免小组件被文字和图表挤满。

## 设计配置

每个用户设计包含：稳定 UUID、名称、模板、默认尺寸、主指标、按顺序排列的辅助指标、图表类型/序列/日期范围/粒度、账本范围、账户/分类/标签筛选、点击动作、金额隐私显示、背景配置和更新时间。

指标首批覆盖今日/周期收支、预算剩余与使用率、结余、净资产、资产/负债、账户余额、交易笔数和储蓄率。图表只表达一个问题：收支趋势、预算消耗、净资产变化或账户余额变化。

## 背景与视觉

背景支持内置主题、纯色和本地相册图片。用户图片支持裁切焦点和明暗遮罩；图片作为不透明表面使用，不引入玻璃、模糊或折射效果。文字、图表和状态必须满足对比度要求，图片失败时回退到纯色主题。

组件遵循“大数字 + 小指标 + 一个视觉重点”的层级。缺率、超支、过期和隐藏金额必须有文字状态，不能只靠颜色表达。

## 用户流程

“我的 → 桌面小组件”分为“基础模板”和“我的小组件”两个区域。

新建流程：选择模板和尺寸 → 选择账本 → 填充主/辅助指标 → 配置图表范围与筛选 → 选择背景与点击动作 → 预览 → 保存到“我的小组件”。

管理流程：预览、编辑、复制、重命名、删除、添加到桌面；桌面添加只能从已保存设计发起。Android 配置 Activity 也只展示已保存设计，并把选中的设计 ID 与新 `appWidgetId` 绑定。

## 导出与导入

备份 JSON v3 增加 `userWidgets`。定义中保存配置和背景资源引用，不保存 `appWidgetId`。内置背景保存主题 ID；本地图片复制为应用资源并随主动备份导出，导入时重新生成本地资源 ID。

导入先校验枚举、尺寸、插槽数量及账本/账户/分类/标签引用；无效引用清理或回退到当前账本和空筛选，不影响账目导入。旧版备份没有 `userWidgets` 时按空列表处理。恢复后设计保留在“我的小组件”，用户重新选择要添加的桌面实例。

清除本地数据时同时清除设计和设备绑定；设计配置不包含密钥、口令、WebDAV 凭证、AI 凭证或聊天历史。

## 刷新与点击

交易、退款、预算、汇率、账户和账本变化后刷新相关设计的所有实例；跨日和跨预算周期重新计算，失败时保留可解释的旧数据并显示刷新状态。

整卡点击使用设计主动作；图表区域进入带相同账本、日期范围和筛选的统计页；快速记账按钮预填设计指定的账本、类型、账户和分类。

## 开发阶段

1. 建立 `UserWidgetDefinition`、背景资源和 `WidgetPlacement` 模型，完成 v3 备份往返与旧配置迁移。
2. 重做“我的小组件”管理页、创建/编辑/复制/删除和多尺寸预览。
3. 增加统一 Android `UserWidgetProvider`、配置 Activity、尺寸布局、背景 bitmap 与点击路由。
4. 把设计 ID 绑定到桌面实例，实现编辑同步、删除解绑和刷新调度。
5. 兼容现有四个 Provider，完成真机/模拟器、浅深色、大字体、不同启动器和导入恢复验收。

本方案不改变交易、预算、退款和多币种计算口径；小组件只读取这些领域已有的权威结果。
