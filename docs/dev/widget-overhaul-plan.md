# 桌面小组件重构方案

状态：产品规格草案（2026-09-12）

## 目标

Veri Fin 的桌面小组件从固定数字展示升级为可配置的桌面财务仪表盘，同时保留快速记账入口。用户应当在不打开应用的情况下快速了解账本状态、发现趋势，并能直接进入下一步操作。

本方案采用「预设布局 + 数据插槽」：用户可以选择账本、指标、筛选条件、图表数据和日期范围，但不提供完全自由的拖拽排版、任意颜色或任意字体。

## 产品原则

- 每个桌面小组件实例独立配置；同一用户可以同时放置多个账本、账户或指标组合。
- 所有账目数据来自当前账本的 SQLite 权威数据，组件只是只读投影。
- 预算遵循账本的自定义预算周期；统计趋势遵循自然日、自然月等报表口径，不混用两套时间含义。
- 多币种汇总始终使用账本本位币；缺少必要汇率时显示缺率状态，不显示部分总额。
- 组件可以展示敏感金额，因此提供“显示金额 / 仅显示趋势或状态”选项。
- Android 启动器的尺寸和刷新限制不可控，布局采用少量稳定模板，所有文字和图表都要能在窄尺寸与大字体下退化。

## 首批组件

### 1. 快速记账

小尺寸显示今日支出与“记一笔”；中尺寸增加收入、支出、转账快捷入口；大尺寸增加本月支出或本期支出。

可配置项：账本、默认记账类型、默认账户、默认分类、是否显示今日支出。

点击快捷入口打开快速记账并预填配置；点击统计区域打开交易列表并定位到今天。

### 2. 预算进度

小尺寸显示本期剩余预算和使用率；中尺寸显示进度环、已用、剩余和剩余日均；大尺寸增加最需要关注的分类预算和预算趋势。

可配置项：账本、总预算或指定分类预算、是否显示日均、是否显示超支分类、金额显示方式。

点击组件进入对应账本和预算周期；点击分类提醒进入该分类预算明细。

### 3. 收支趋势

小尺寸显示一个主指标和迷你折线；中尺寸显示折线图与收入/支出/结余指标；大尺寸增加指标卡或分类摘要。

可配置项：账本、收入/支出/结余/预算消耗中的一个或多个序列、最近 7/30/90 天或当前预算周期、本年、按账户/分类/标签筛选、按日/周/月聚合。

点击组件进入统计分析，并带入相同账本、日期范围和筛选条件。

### 4. 净资产

小尺寸显示净资产；中尺寸增加总资产、总负债和变化值；大尺寸增加净资产趋势或资产/负债结构。

可配置项：账本、是否包含隐藏账户、净资产或资产/负债序列、对比区间、金额显示方式。

点击组件进入资产页；点击趋势区域进入资产报告。

## 指标插槽

主指标每个组件只能有一个，辅助指标最多三个。首批指标目录如下：

- 今日支出、本周支出、本月支出、本期支出
- 本月收入、收支结余、储蓄率、交易笔数
- 本期预算、已用预算、剩余预算、预算使用率、剩余日均
- 净资产、总资产、总负债
- 指定账户余额及余额变化
- 支出最高分类、分类预算使用率

指标需要声明适用的模板、时间口径、币种口径和可用筛选项，配置页只展示当前组合可用的指标，避免用户选出无法解释的组合。

## 图表插槽

图表是独立插槽，不与主指标绑定。首批只提供单图表模板，避免在小屏上堆叠信息：

- 折线图：收入、支出、结余、净资产、账户余额
- 预算图：累计支出与预算上限
- 进度环：预算使用率

日期范围提供最近 7 天、最近 30 天、最近 90 天、当前预算周期和本年度。应用根据范围自动建议日、周或月粒度，但用户可以在允许的范围内修改。小组件上的图表只显示必要刻度，详细数据交给点击后的应用页面。

## 配置与入口

“我的 → 桌面小组件”作为统一管理页，包含可添加的模板和当前已配置实例。

新增或编辑流程：

1. 选择模板和桌面尺寸预览。
2. 选择账本，默认使用当前账本，也允许固定到指定账本。
3. 选择主指标、辅助指标和筛选条件。
4. 对带图表的模板选择序列、日期范围、粒度和图表开关。
5. 选择点击后的目标页面，并设置金额是否显示。
6. 保存配置，随后请求添加到桌面或更新现有实例。

配置按 Android `appWidgetId` 保存，不能使用单一全局配置。账本被删除或不可用时，组件进入明确的“需要重新选择账本”状态，不静默切到其他账本。

## 视觉与可读性

小组件遵循 Veri Fin 当前纯色材质规范：不透明表面、细描边、轻阴影、明确的主次数字层级。高级感来自信息密度、数字排版、图表比例和状态反馈，不引入玻璃、模糊或整屏渐变。

每个组件最多突出一个视觉重点。金额使用统一的单位显示和语义色；缺率、过期和超支必须有文字状态，不能只靠颜色。组件需支持系统浅色/深色、大字号、窄尺寸和屏幕阅读器可读标签。

## 刷新与过期

- 交易、退款、预算、汇率、账户、账本切换和相关偏好保存后主动刷新。
- 跨自然日时重新计算今日指标；跨预算周期时重新计算新周期预算，不能沿用旧周期缓存。
- 设备重启、应用升级和组件恢复后重新读取配置并刷新。
- Android 未及时调度刷新时显示最后一次数据及“打开应用刷新”状态，不能伪装成实时数据。
- 刷新失败保留上次可解释数据并记录隐私友好的本地日志。

## 兼容策略

现有快速记账、预算和净资产 Provider 的组件名称与入口保留为兼容层。旧实例继续显示旧布局，新实例使用统一配置和新模板；用户可以从小组件管理页逐步编辑或替换，不需要卸载应用、清除数据或重新导入账目。

原生组件继续负责 `RemoteViews` 外壳、尺寸适配和点击路由；Flutter 负责配置界面、数据计算和预览。趋势图由 Flutter 生成轻量图像交给原生组件显示，避免在 Android 小组件内重复实现账目计算。

## 验收标准

- 同一桌面可以同时放置至少两个不同账本、不同筛选条件的同类组件，数据互不串账。
- 修改一个组件配置不会改变其他组件实例。
- 预算组件遵循自定义预算周期，统计组件遵循自然月/自然日口径。
- 缺汇率、账本删除、无预算和无交易时都有明确空态或状态，不显示误导性的 0。
- 交易保存、预算修改、汇率修改、账本切换后，相关组件在下一次系统允许刷新时展示新数据。
- 点击组件能进入正确页面，并带入账本、日期范围和筛选条件。
- 393×852 配置页、窄屏、大字号、浅色/深色和 Android 真机启动器验收通过。
- 旧版本已放置的组件仍可正常渲染；升级过程不要求清除应用数据。

## 开发阶段

1. **规格冻结**：确认指标目录、图表目录、尺寸布局、默认值和点击路由。
2. **配置基础**：建立按实例保存的配置、版本迁移、账本删除处理和统一数据快照。
3. **渲染重构**：实现四类模板、尺寸适配、图表图像和过期状态。
4. **配置体验**：完成管理页、预览、添加到桌面和已有实例编辑。
5. **兼容与验收**：覆盖旧组件迁移、系统刷新、重启、多账本、多币种、大字号和真机启动器。

本方案确认后，下一步先实现配置模型与统一数据快照，再实现组件 UI；不会先改动账目计算或备份格式。
