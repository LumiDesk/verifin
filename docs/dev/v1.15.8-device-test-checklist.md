## 一、测试前准备

- [ ] 在旧版本中手动创建一份可恢复备份，确认文件已写入 Downloads 或备份目录。
- [ ] 记录当前活动账本、账户余额、交易总数、最近一笔交易、默认账户和预算金额。
- [ ] 至少准备一个含真实测试数据的账本，不要只用空白首启动数据。
- [ ] 如需测多币种，准备一个外币账户、一条有效汇率和一个故意缺汇率的币种。
- [ ] 如需测 WebDAV，准备一个可用测试目录；不要使用唯一的生产备份目录做破坏测试。
- [ ] 准备一个合法备份、一个空文件、一个错误格式文件和一个可导入账单样例。
- [ ] 记录应用锁、提醒、小组件、AI 配置等设备本地设置，升级后用于比对。

## 二、下载与升级安装

- [ ] 从 GitHub `v1.15.8` **预发布**下载 arm64 APK，不使用第三方转存包。
- [ ] 文件名包含 `verifin-v1.15.8`、`arm64` 和短提交号。
- [ ] 在 v1.15.7 上直接覆盖安装，系统未提示签名不一致。
- [ ] 首次启动不白屏、不闪退，也未出现数据库降级错误页。
- [ ] “我的 → 关于/版本”显示 `v1.15.8+104`。
- [ ] 旧账本、账户、余额、交易、预算、分类、标签和附件均保留。
- [ ] 默认账户、主题、语言、金额格式、提醒和应用锁设置均保留。
- [ ] 强制停止应用后重新打开，数据仍一致。

## 三、基础冒烟

- [ ] 首页、资产、看板、我的四个 Tab 均可打开和左右滑动。
- [ ] 浮动根导航、快捷记账按钮和系统返回行为正常。
- [ ] 手动记一笔支出，保存后首页和账户余额立即更新。
- [ ] 打开交易详情、账户详情、预算和设置页，无溢出或异常空白。
- [ ] 深色和浅色主题切换后文字、图标、卡片均可读。
- [ ] 中文与英文切换后页面和轻提示没有硬编码语言混杂。

## 四、轻提示核心能力

### 视觉与位置

- [ ] 普通提示约 168×40dp，带操作按钮时约 240×40dp，不是整宽横条。
- [ ] 提示位于浮动根导航上方，不遮挡导航或快捷记账按钮。
- [ ] 图标、消息、`×N`、操作文字和关闭图标视觉对齐。
- [ ] 深色模式轮廓和阴影清楚但不过亮；浅色模式与页面背景有足够区分。
- [ ] 信息/成功/警告/错误分别使用蓝、绿、黄、红语义色，卡片本体不整块染色。
- [ ] 长文案没有越界；必要时单行省略，不挤坏操作和关闭按钮。

### 时长与关闭

- [ ] 2 秒短提示大致按时消失，进度线连续递减。
- [ ] 4 秒默认提示和 8 秒长提示时长明显不同。
- [ ] 常驻提示不显示进度线，也不保留空白槽；正文垂直居中。
- [ ] 点击关闭只移除当前提示，其他提示位置平滑收拢、计时不重置。
- [ ] 连续触发多条时由下向上堆叠，最多同时显示四条。
- [ ] 第五条以后进入等待队列，前一条结束后按顺序出现。

### 去重、操作与导航

- [ ] 快速重复触发同类错误时合并为一条并显示 `×N`，不会刷屏。
- [ ] 重复触发后计时从头开始，文案/tone 可原位更新。
- [ ] 带“撤销”等操作的提示可点击，点击后提示平滑关闭。
- [ ] 提示显示期间切换 Tab，提示仍在且进度连续。
- [ ] 提示显示期间进入详情页再返回，提示仍是同一条。
- [ ] 应用切到后台等待数秒再回来，提示从原进度继续而非在后台消失。
- [ ] 开启应用锁时退后台再回来，锁屏能覆盖账目和提示内容。

## 五、根级反馈

- [ ] 在首页第一次按系统返回键，显示“再次返回退出程序”短提示。
- [ ] 2 秒内再次返回，应用退出。
- [ ] 超过 2 秒再返回，只重新显示提示，不直接退出。
- [ ] 在资产/看板/我的按返回，先回首页，不弹退出提示。
- [ ] 连续触发保存失败时只保留一条错误提示并累加 `×N`。
- [ ] 保存失败提示使用红色、高优先级和长时长，不会伪装成保存成功。

## 六、简单反馈场景

- [ ] AI 设置清空配置后显示成功提示。
- [ ] 生物识别验证未通过时显示警告；修改应用锁方式后显示成功。
- [ ] 软件日志“复制全部”后显示成功提示，剪贴板内容可粘贴。
- [ ] 不支持截图识账的环境显示警告；支持的设备不误报。
- [ ] 信用卡/信用账户完成还款后显示成功，余额与欠款同步变化。
- [ ] 发送测试提醒后显示成功；拒绝通知权限后显示警告。
- [ ] 请求添加桌面小组件时，支持/不支持结果对应成功或警告。
- [ ] 没有可用账户时设置默认账户，显示警告而非打开空选择器。
- [ ] 账户详情复制卡号后显示成功，卡号已进入剪贴板。

## 七、账户、分类、汇率与交易反馈

### 账户与账本

- [ ] 缺少汇率时尝试记录余额调整，显示明确警告且不伪装成功。
- [ ] 有财务数据的账户尝试改币种，显示币种锁定警告。
- [ ] 有财务数据的账本尝试改本位币，显示锁定警告。
- [ ] 旧账本完成一次性币种确认后显示成功；模拟保存失败时显示错误。
- [ ] 删除账户导致周期规则停用时，删除弹窗关闭后提示仍可见。

### 分类

- [ ] 无可移动目标时显示警告。
- [ ] 有子分类的分类执行合并/删除时提示先处理子分类。
- [ ] 系统分类、已被交易使用、已被周期规则使用的分类不可删除并有对应提示。
- [ ] 每种类型最后一个分类不可删除并有对应提示。
- [ ] 分类合并成功显示成功和影响笔数；失败显示红色错误。
- [ ] 非法移动分类时显示警告。

### 汇率、面板与周期规则

- [ ] 新建/编辑汇率成功显示成功；保存或删除失败显示红色错误并去重。
- [ ] 尝试关闭最后一个首页/看板面板，显示警告且开关状态不变。
- [ ] 手动补记周期交易后显示生成数量；失败显示红色错误。

### 交易

- [ ] 转账的转入账户为空或与转出账户相同时显示警告，无法保存。
- [ ] 批量改分类后显示实际修改数量。
- [ ] 批量改账户后显示实际修改数量。
- [ ] 上述提示消失不会退出多选流程或改变未选交易。

## 八、数据管理与备份

### 本地目录、备份与导出

- [ ] 选择备份目录成功后显示目录名称。
- [ ] 目录选择失败时显示红色错误并写入软件日志。
- [ ] “立即备份”期间仍显示不可关闭进度框，完成后显示备份文件名。
- [ ] 备份失败时关闭进度框、显示红色错误并写入日志。
- [ ] 导出本地备份成功时说明文件已导出；开启加密时带加密提示。
- [ ] 导出失败显示红色错误并写入日志。
- [ ] 设置备份加密口令后显示成功。
- [ ] 下载 CSV 模板成功/失败提示正确。
- [ ] 导出交易 CSV 成功/失败提示正确，失败写入日志。

### WebDAV

- [ ] 保存 WebDAV 配置后显示成功。
- [ ] 上传开始时出现常驻“正在上传”提示，无进度空槽。
- [ ] 上传成功后同一条提示原位变为成功并开始倒计时，不叠加第二条。
- [ ] 使用错误地址/凭证时，同一条提示原位变为红色错误并写入日志。
- [ ] 远端列表读取失败显示红色错误并写入日志。
- [ ] 远端没有备份时显示中性说明。
- [ ] 选择远端备份、确认并恢复成功后显示成功，数据重载一致。
- [ ] 远端备份格式错误或下载失败时显示红色错误并写入日志。

### 平台账单导入

- [ ] 选择空文件显示警告。
- [ ] 无交易、无账户且无错误行时提示“没有可导入内容”。
- [ ] 有错误行时仍进入现有结果详情，不用轻提示隐藏逐行错误。
- [ ] 导入预览取消时不落库、不显示成功。
- [ ] 确认导入后按交易数或纯账户数显示成功；跳过行数后缀正确。
- [ ] 错误格式显示带原因的红色提示，重复错误按平台去重。
- [ ] 解析异常显示“检查文件”错误并写入日志。

### 本应用备份导入

- [ ] 合法 zip/加密备份导入成功并显示成功。
- [ ] 加密备份输错口令仍走现有口令错误流程，不覆盖本地数据。
- [ ] 格式错误显示红色格式提示并写入日志。
- [ ] 其它导入异常显示“检查文件”错误并写入日志。
- [ ] 导入成功后账本、账户、交易、预算、汇率和附件一致。

## 九、回归与稳定性

- [ ] 快速记账、AI 草稿、退款/报销、转账手续费行为未变化。
- [ ] 资产总额、预算、统计、图表和桌面小组件数值未变化。
- [ ] 本地备份、加密备份、WebDAV、CSV 与第三方导入均可完成。
- [ ] 应用锁、通知提醒、分享识账和快捷磁贴入口正常。
- [ ] 多次切换前后台、旋转屏幕或改变显示大小后无崩溃、重影、卡顿。
- [ ] 打开键盘时提示不会被键盘完全遮挡或挡住主要保存按钮。
- [ ] 连续使用 15 分钟后没有提示永久残留、队列不释放或点击穿透。
- [ ] “我的 → 软件日志”没有新增未处理异常；日志不包含凭证或完整账目原文。
- [ ] 强制停止并重启后权威数据与测试前记录一致。
