## 1. 背景与纠偏

本次工作的目标不是单独美化某个看板，而是建立一套可复用的数据卡片与图表体系，覆盖首页、看板、资产、预算、统计、交易、账户、AI 结果和“我的”等页面。后续新增图表、指标卡、排行、进度条和空状态都应优先使用这套体系，而不是继续在页面内复制局部实现。

维护者已明确纠正两项历史结论：

- **没有形成“不使用外部图表库”的决策。** 维护者一直倾向于采用成熟外部组件库；必要时可以让图表行为服从组件库的能力，再由项目做适配。
- **没有形成“预算圆环必须自绘”的决策。** 旧文档中的相关表述未经维护者确认，不能作为约束继续沿用。预算圆环、分类环形图和其他图表一样，统一迁移到外部图表库；如果外部库无法满足某项要求，调整视觉要求或更换外部库，不退回首绘。

维护者还明确要求：空状态直接采用 **Lottie 或 Rive**，并封装成可跨页面复用的通用组件。

### 1.1 已确认决策

| 主题 | 已确认决策 |
| --- | --- |
| 标题 | 使用两个薄封装：一级卡片标题和二级卡内区块标题，不做一个万能标题组件 |
| 指标块 | 使用小型组件族；允许通过样式参数表达不同页面的既有视觉差异，但同类数据单元共享结构 |
| 图表 | 最终完全替换为外部组件库图表，项目内不再保留自绘数据图表 |
| 图表库 | `fl_chart` 为首选候选；它是 MIT 许可、采用度最高、仍在维护；原型不通过时再评估 `syncfusion_flutter_charts` 或 `graphic` |
| 空状态 | 使用 Lottie 作为默认动画方案，Rive 作为需要状态机或交互时的备选；统一封装为通用空状态组件 |
| 范围 | 全项目所有数据图表一次性替换，不限于看板页；看板作为第一批可评审页面 |
| 进度条 | 横向进度条不算图表，继续使用统一的 Flutter 进度条组件 |
| 面板管理页 | 只有开关和排序，没有图表；本次不改 |

## 2. 本次目标与非目标

### 2.1 目标

- 统一数据卡片的标题、指标、排行、进度条、图表、颜色、间距和空状态。
- 采用成熟外部图表库作为默认渲染基础，并在项目内建立稳定的图表适配层。
- 采用 Lottie 建立统一空状态组件，支持跨页面复用；Rive 作为后续交互型动画备选。
- 通过规范和组件收敛，让后续新增图表只需要配置数据和展示属性，不重复实现坐标轴、命中、气泡、图例和无障碍。
- 为看板面板和首页面板保留现有开关、排序、持久化和备份语义。

### 2.2 非目标

- 不修改账目、预算、退款、多币种、备份和导入导出的数据口径。
- 不重做根导航、页面骨架、快速记账流程和设置持久化。
- 不要求一次性替换所有现有图表；采用分阶段迁移，允许旧实现短暂共存。
- 不把图表库选择塞进 `UNIFIED_DESIGN_PREVIEW`。该参数继续只控制布局密度与排版。
- 不在本分支修改 Dart 代码、Gradle、CI 或发布流程。

## 3. 术语定义

### 3.1 标题的两级

“两级”指的是同一张卡片内部的两个文字层级，不是两套页面标题组件。

| 级别 | 用途 | 示例 | 建议字号 |
| --- | --- | --- | --- |
| 一级：卡片标题 | 说明整张卡片的数据主题 | “分类统计”“预算执行”“最近交易” | `titleMedium` / `w800` |
| 二级：卡内区块标题 | 说明卡片内部某个子区块或指标组 | “本期支出”“信用额度”“同比 · 环比” | `titleSmall` / `w800` |

已确认采用两个薄封装：`VeriCardTitle` 与 `VeriSectionTitle`。两者共享同一套字号、字重、间距、右侧信息对齐和可点击语义，不合并成一个万能组件。

### 3.2 指标块

“指标块”指卡片里“标签 + 数值（+ 补充说明）”之类的小型数据单元，不是指底层账目数据重复。典型位置包括：

- 看板顶部“本月收入 / 本月支出 / 本月结余”；
- 首页概览的“大数字 + 摘要胶囊 + 三个小指标”；
- 预算总览的四个预算指标；
- 账户详情的“余额 / 收入 / 支出”；
- 信用账户的“已用额度 / 可用额度 / 本期账单”；
- AI 统计结果卡。

现在这些位置由多份私有组件分别渲染，视觉和代码实现重复。统一目标是建立一个小型组件族，不是把不同业务数据合并。

维护者已确认：不同位置的指标块视觉并不完全相同，因此组件需要保留样式参数，例如 `variant`、`size`、`tone`、`showIcon`、`showBackground`、`alignment` 和 `detail`。参数只表达既有视觉差异，不让调用方重新拼布局。

### 3.3 排行行

“排行行”指“图标或序号 + 名称 + 金额 + 占比 + 进度条 + 笔数”这类列表行。看板的分类明细、标签统计，统计分析页的分类/子分类/标签排行，以及 AI 排行结果都存在同类行。

排行行的视觉可以统一，但聚合逻辑不能统一：分类按顶级祖先聚合，标签允许多标签重复计入，统计分析页还要支持不同时间范围和收入维度。

## 4. 现状盘点

### 4.1 数据卡片分布

| 页面 | 主要数据卡片 |
| --- | --- |
| 首页 | 概览走势卡、最近交易、月度预算、日历、周期缺率提醒 |
| 看板 | 本月摘要、预算执行、分类环形、分类明细、标签统计、日趋势、月度结构 |
| 资产 | 净资产封面卡、缺汇率提示、账户分区卡、隐藏账户入口 |
| 预算 | 预算总览主卡、四指标格、按日预算、预算洞察、近 6 期趋势、历史对比、分类预警、分类预算树 |
| 统计分析 | 收支概览、同比环比、趋势、分类排行、标签排行 |
| 收支统计详情 | 总金额趋势卡、按天/按月统计列表 |
| 交易列表 | 支出/收入/结余摘要卡、日期分组交易卡 |
| 账户详情 | 余额/收入/支出指标、余额趋势、信用额度卡 |
| AI 结果 | 统计卡、排行卡、趋势卡、交易列表卡、表格卡 |
| 我的 | 个人统计项、功能宫格 |

### 4.2 当前主要问题

1. 标题行有三套以上写法，字号、字重和对齐规则不统一。
2. 同类指标块以私有组件重复实现，视觉容易漂移。
3. 排行行存在多份实现，金额格式化、进度条高度和截断数量不一致。
4. 进度条高度、圆角、底色透明度和语义色分散。
5. 图表高度分布为 96、112、132、138、146、150、156、172、180 等，没有按角色分类。
6. 图表全部为项目内自绘，缺少外部库适配层，新增图表成本高。
7. 图表颜色、分类色和坐标轴颜色没有集中定义，存在硬编码颜色。
8. 空状态只有基础图标和文字，缺少统一插画、动画、尺寸和操作层级。

## 5. 外部依赖选型

### 5.1 图表库

采用外部图表库是本次的硬性方向。最终目标是删除项目内全部自绘数据图表，只保留外部组件库图表和项目适配层。选型需要满足以下要求：

- 支持折线、柱状、环形/饼图，并尽量支持柱线组合图。
- 支持点击、横向拖动、选中高亮和数据气泡。
- 支持坐标轴标签、网格线、长金额标签和文本缩放。
- 支持浅色/深色主题、透明或卡片背景、局部渐变（如需要）。
- 支持无障碍语义；无法直接提供时，项目适配层必须补齐。
- 不联网、不采集数据、不影响 R8 和 APK 体积预算。
- 许可证允许 GPL-3.0-or-later 项目使用。

截至 2026-10-10，对 pub.dev 的初步事实核对如下：

| 库 | Like 数 | 最新版本 | 最近发布 | 备注 |
| --- | ---: | --- | --- | --- |
| `fl_chart` | 7197 | 1.2.0 | 2026-03-13 | 采用度最高，MIT 许可，首选候选 |
| `syncfusion_flutter_charts` | 3639 | 35.1.39 | 2026-10-07 | 功能全、发布活跃；许可证和体积需重点核对 |
| `graphic` | 900 | 2.7.0 | 2026-02-25 | 能力抽象强，迁移成本和学习成本较高 |
| `community_charts_flutter` | 223 | 1.0.4 | 2024-05-15 | 维护活跃度不足 |
| `charts_flutter` | 1329 | 0.12.0 | 2021-11-03 | 已长期停更，不选 |
| `d_chart` | 205 | 3.0.0 | 2025-04-26 | 采用度偏低 |

已确认方向：

1. `fl_chart` 作为首选实现，先做技术原型和验收矩阵。
2. 如果预算趋势组合图或环形图不能满足验收，再评估 `syncfusion_flutter_charts` 或 `graphic`；不因为原型失败退回自绘。
3. 页面不直接依赖具体图表库，统一通过项目内的 `VeriLineChart`、`VeriBarChart`、`VeriDonutChart`、`VeriComboChart` 之类适配层使用。
4. 迁移完成后删除自绘数据图表；不能因为“以前已经写了”而保留。
5. 预算圆环和分类圆环同样迁移到外部库，项目不再保留自绘数据图表。

本轮确认需要迁移并最终删除的自绘数据图表：

| 当前实现 | 位置 | 处理 |
| --- | --- | --- |
| `TrendLinePainter` | `lib/app/chart_painters.dart` | 迁移到外部折线图适配层 |
| `BarChartPainter` | `lib/app/chart_painters.dart` | 迁移到外部柱状图适配层 |
| `BudgetRingPainter` | `lib/app/chart_painters.dart` | 迁移到外部环形/进度图适配层 |
| `_BudgetTrendPainter` | `lib/pages/budget_trend_chart.dart` | 迁移到外部组合图适配层 |
| `_CategoryDonutPainter` | `lib/pages/reports_page.dart` | 迁移到外部环形图适配层 |
| `_CategoryCalloutPainter` | `lib/pages/reports_page.dart` | 由外部图表标注能力或外层布局替代 |

以下 `CustomPainter` 不是数据图表，不属于本次“删除自绘图表”的范围：

- 液态玻璃底栏的透镜、高光和输入边界绘制；
- 停靠底栏的圆点与扫线动画；
- 应用锁图案输入棋盘；
- 其他纯装饰、手势或材质绘制。

旧版图表几何函数、命中函数、气泡绘制和预算圆环像素回归测试在迁移完成后必须重写或删除；验收改为外部图表库适配层的交互、样式和无障碍测试。

图表库原型验收矩阵：

| 验收项 | 最低要求 |
| --- | --- |
| 折线图 | 点击/拖动选中、气泡、坐标轴、长短标签 |
| 柱状图 | 点击/拖动选中、纵轴刻度、长标签换行或截断 |
| 环形图 | 分段点击、中心内容、图例或外侧标注、深浅色 |
| 组合图 | 柱和线共用坐标区，气泡区分序列 |
| 文本缩放 | 1.0、1.3、1.5 倍下不裁切、不重叠 |
| 主题 | 浅色、深色、图片背景卡片 |
| 无障碍 | 整图摘要、选中数据可读 |
| 性能 | 393×852 与 360dp 下滚动稳定，无明显掉帧 |
| 构建 | release/R8 可用，APK 体积增量可接受 |

### 5.2 空状态动画库

空状态确定使用 Lottie 并封装为通用组件；Rive 只在需要状态机或交互时再引入。初步事实：

| 库 | Like 数 | 最新版本 | 最近发布 | 适合场景 |
| --- | ---: | --- | --- | --- |
| `lottie` | 4579 | 3.6.1 | 2026-09-18 | 播放设计师导出的 JSON 动画，接入简单 |
| `rive` | 1948 | 0.14.11 | 2026-08-03 | 状态机与交互能力更强，工具链更重 |
| `flutter_animate` | 4254 | 4.5.2 | 2024-11-25 | 轻量入场/过渡动画，不是位图/矢量资产播放器 |
| `simple_animations` | 2005 | 5.3.0 | 2026-05-23 | 代码式动画，适合微动效 |

已确认方向：

- 纯播放型空状态动画默认选 `lottie`；它是 MIT 许可，接入成本低、采用度高。
- 如果后续确实需要状态机、交互或可切换状态，再评估 `rive`。
- 空状态组件只负责资产播放、尺寸、语义和降级；业务页面只传状态和文案。
- 必须支持系统“减少动态效果”：开启时停在动画首帧或使用静态占位。
- 动画资产必须随 APK 本地打包，不联网加载；每个资产的体积和缓存策略要单独记录。
- 资产提供方可以是设计师、开源素材或后续自建；无论来源都要确认许可证并登记来源。

## 6. 统一组件体系

以下为组件族设计草案；核心方向已确认，最终命名与 API 细节在实现前写入组件注册表。

### 6.1 数据卡片外壳

可以考虑引入 `VeriDataCard`，但不要取代 `VeriCard`：

- `VeriCard`：通用容器，继续服务设置、表单和普通信息卡。
- `VeriDataCard`：数据展示语义容器，统一卡片标题、meta、右侧 action、内容区和 footer。

`VeriDataCard` 负责：

- 卡片标题行；
- 标题右侧的单位、周期、筛选或操作入口；
- 内容区默认间距；
- 空态、加载、错误状态的插槽；
- 底部说明或图例。

如果引入后会造成过度封装，则保留 `VeriCard`，只统一标题行和内容间距。

### 6.2 标题组件

已确认提供两个标题薄封装，而不是让页面手写 Row：

- `VeriCardTitle`：一级卡片标题。
- `VeriSectionTitle`：二级卡内区块标题。
- `VeriTitleActions`：右侧的 meta、图例、筛选、更多操作容器。

关键规则：

- 标题自然宽度靠左，右侧信息贴内容区右边。
- 右侧文本单行截断，不挤压标题到不可读。
- 可点击标题保留完整触控区域，但首页最近交易等既有“无 hover 横条”规则继续生效。
- 同一卡片内不混用 `w800`、`w900` 和不同 `titleMedium/titleSmall`。

### 6.3 指标块组件族

已确认至少区分三类，不做一个万能组件：

| 组件 | 用途 | 示例 |
| --- | --- | --- |
| `VeriMetricGroup` | 水平排列多个等宽指标 | 本月收入/支出/结余 |
| `VeriMetricTile` | 带图标或底色的卡片内小块 | 预算四宫格、首页三个指标方块 |
| `VeriComparisonMetric` | 当前值 + 基准值/变化 | 同比环比、本月与上月 |

统一属性包括：标签、数值、数值颜色、补充说明、是否等宽、是否紧凑、是否截断。不同页面既有样式通过受控参数表达，例如：

- `variant`：普通、带底色、带图标、强调；
- `size`：紧凑、标准、大数字；
- `tone`：主色、收入、支出、警告、中性；
- `detail`：补充说明、变化值、笔数；
- `layout`：横向并排、纵向堆叠、两列对比。

参数用于保留现有页面的视觉差异，但调用方不再自行决定字号、间距、圆角和进度条样式。

### 6.4 排行行组件

建议统一为 `VeriRankRow`：

- `leading`：图标、序号或颜色点；
- `label`：分类、标签或维度名称；
- `amount`：已格式化金额；
- `percent`：进度值；
- `count`：笔数；
- `progressTone`：进度条语义色；
- `onTap`：可选下钻；
- `showChevron`：是否显示右侧箭头。

聚合成 `VeriRankRowData` 的逻辑仍由各页面或领域纯函数负责。看板、统计分析和 AI 结果只共享行渲染，不共享数据口径。

### 6.5 进度条组件

建议统一为 `VeriProgressBar`：

- `value`；
- `tone`：主色、收入、支出、警告、中性；
- `size`：细条、标准条；
- `backgroundColor`：默认使用统一表面色；
- `semanticsLabel`；
- 可选 `valueLabel`。

预算进度继续由 `budgetProgressColor` 一类业务函数决定状态色，但渲染统一走 `VeriProgressBar`。

### 6.6 图表适配层

项目内新增图表适配层，页面只依赖项目 API；适配层内部使用外部图表库，项目不再新增自绘数据图表：

> 落地名称与本节草案不同，以实际实现为准：折线 `InteractiveTrendChart`、柱状
> `InteractiveBarChart`（含 `VeriBarSeries` 分组双柱）、环形 `VeriDonutChart`、
> 进度环 `VeriBudgetRing`，气泡模型 `ChartTooltip` / `ChartTooltipLine`。
> 草案里的 `VeriLineChart` / `VeriBarChart` / `VeriComboChart` / `VeriChartCard` /
> `VeriChartLegend` / `VeriChartInteraction` 都没有落地，不要按草案名字找代码；
> `VeriComboChart` 曾以 `InteractiveComboChart` 实现过一版，预算近 6 期趋势改成
> 双柱后已删除。

- `VeriLineChart`：折线图；
- `VeriBarChart`：柱状图；
- `VeriDonutChart`：环形/饼图；
- `VeriComboChart`：柱线组合图；
- `VeriChartCard`：图表卡片外壳，统一标题、高度、空态和单位；
- `VeriChartLegend`：图例；
- `VeriChartTooltip`：气泡内容模型；
- `VeriChartInteraction`：点击、拖动、选中和取消规则。

适配层负责把项目统一数据模型转换成外部图表库配置，并补齐：

- 金额格式化；
- 单位隐藏规则；
- 语义色；
- 深浅色主题；
- 文本缩放；
- 无障碍摘要；
- 空态和错误态。

硬性规则：

- 任何页面不得直接 import 具体图表库；
- 任何数据图表不得新增 `CustomPainter` 实现；
- 现有 `chart_painters.dart` 中的数据图表在迁移完成后删除；
- 后续更换图表库时，只改适配层。

### 6.7 空状态组件

建议将现有 `EmptyState` 升级为 `VeriEmptyState`：

- `type`：无数据、筛选无结果、缺汇率、未设置、加载失败；
- `animation`：Lottie/Rive 资产或静态降级；
- `title`；
- `description`；
- `action`：可选操作；
- `compact`：卡片内紧凑模式；
- `tone`：中性、警告、错误；
- `semanticsLabel`。

要求：

- 支持减少动态效果；
- 支持浅色/深色主题；
- 动画资产尺寸有上限；
- 无动画资产时自动降级为现有图标方案；
- 文案说明“为什么空”和“可以做什么”，不写无意义安慰语。

## 7. 视觉与交互规范草案

### 7.1 卡片

- 继续保持不透明实色表面、统一圆角和描边。
- 数据卡片的横向内容边距统一，页面不再各写 `14/16/18`。
- 卡片标题与内容区之间、指标组与图表之间的垂直间距统一。
- 可跳转数据卡片使用明确入口或轻量点击反馈，不在大面积图表区域触发跳转。

### 7.2 指标

- 标签、数值、补充说明的字号和颜色按组件族统一。
- 金额为 0 使用中性色，不显示 `-0`。
- 收入、支出、转账、警告等语义色必须经 `veriSemantic` 族获取。
- 单币种隐藏单位规则继续适用于所有聚合指标。

### 7.3 进度条

- 只允许少量高度档位，例如细条与标准条。
- 圆角统一为胶囊形或统一的固定圆角，不再出现 6/99/999 混用。
- 背景色透明度和前景语义色由组件统一决定。
- 预算和信用额度等业务状态通过 `tone` 传入，不在页面手写进度条。

### 7.4 图表高度

建议按角色建立 token，而不是按页面写魔法数字：

| Token | 用途 |
| --- | --- |
| `chartHeightInline` | 首页概览等紧凑趋势 |
| `chartHeightCard` | 看板、预算、统计等标准面板 |
| `chartHeightDetail` | 收支统计详情、账户报告等大图 |
| `chartHeightCover` | 资产封面内趋势 |

具体数值在原型阶段用 360/393dp、1.0/1.3/1.5 倍字号一起验证后确定。

### 7.5 图表交互

- 折线、柱状、环形、组合图都必须支持点击或拖动查看数据。
- 再次点击同一位置或点击图表外取消选中。
- 图表位于可跳转卡片内时，图表区域拦截点击，不触发卡片跳转。
- 气泡内容统一由项目模型生成，外部库只负责展示。
- 饼图/环形图点击后展示选中分段，其余分段弱化。
- 多序列图使用图例和同色标记区分。

### 7.6 图表颜色

建议集中为三层：

1. 语义色：收入、支出、转账、警告、错误、主操作。
2. 分类色：环形图、排行、多序列图的分类色板。
3. 基础色：坐标轴、网格线、标签、气泡、高亮和淡背景。

所有颜色按浅色/深色解析后传入图表适配层。页面不再直接传 `Color(0x...)` 或裸用亮色常量。

### 7.7 文本缩放与窄屏

- 统一在 360dp、393dp、浅色、深色、1.0/1.3/1.5 倍字号下验证。
- 长金额、长分类名、英文标签和月份标签不得溢出或重叠。
- 图表坐标轴标签可稀疏、截断或换行，具体规则写入图表规范。

## 8. 迁移方案

### 阶段 0：规范与原型

- 确认标题、指标、排行、进度条、图表、颜色和空状态规范。
- 建立外部图表库原型，推荐先验证 `fl_chart`。

### 阶段 1：基础组件

- 落地标题组件、进度条组件和空状态组件。

### 阶段 2：指标与排行

- 落地指标组件族和 `VeriRankRow`。
- 迁移看板、首页、预算、统计分析和账户详情。

### 阶段 4：逐页迁移

### 阶段 5：清理与固化

- 删除迁移后不再使用的私有组件。
- 删除 `chart_painters.dart` 中的数据图表和 `budget_trend_chart.dart` 中的组合图绘制；非图表画布保留。
- 更新组件注册表、设计规范、验收清单和选型文档。

## 11. 风险

- 外部图表库的坐标轴、气泡和文本缩放行为可能与现有页面不完全一致。

- Lottie/Rive 资产可能增加 APK 体积，需要单独预算和登记。
- 图表库许可证、维护状态和 R8 行为必须在上线前核验。
- 一次性迁移所有页面容易产生大量视觉回归；必须分阶段提交和验收。
- 面板配置和备份数据包含面板 ID，迁移不得改变既有 ID。
