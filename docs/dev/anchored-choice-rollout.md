# 短静态单选锚点菜单扩展

> 状态：已实现并验证。本文记录 v1.15.1 在 v1.15.0 首轮锚点菜单基础上的扩展范围与保留边界。

## 目标

把“2–8 项、静态、受控、无需搜索或分区”的单选从全宽 Bottom Sheet 改为贴近触发控件的锚点菜单，同时保留页面草稿、明确保存、危险确认和领域长列表 Picker 的既有语义。

公共适配层为 `VeriAnchoredChoice<T>`，底层继续复用 `VeriAnchoredMenuAnchor` 的定位、关闭、返回、动画和 Semantics；页面只提供候选值、当前值、稳定 id、本地化文案和选择回调。

## 已接入范围

| 领域 | 入口 |
|---|---|
| 应用设置 | 主题、语言、货币单位样式、首页记账按钮行为 |
| 数据管理 | 自动备份频率、备份间隔、保留份数 |
| AI | 工具调用协议；菜单副标题展示各协议用途 |
| 周期规则 | 汇率策略、重复频率 |
| 交易列表 | 时间范围、排序方式、报销状态 |
| 收支统计 | 支出 / 收入 / 转账类型筛选 |
| 首页概览设置 | 曲线数据序列 |
| 附件 | 拍照 / 从相册选择；这是无持久选中态的动作菜单，直接使用 `VeriAnchoredMenuAnchor` |
| 账户编辑 | 新建与编辑账户的账户类型；副标题说明卡号/信用能力 |
| 交易编辑 | 无关联退款时可选支出 / 收入 / 转账；已有退款时不构造菜单入口 |
| 个人资料 | 性别 |

## 业务边界

- 设置、备份、AI、周期规则、首页概览、账户、交易和个人资料页面仍先修改本地草稿，只有右上角保存才提交 Controller/KV/SQLite。
- 新建账户切换到不支持卡号的类型时只隐藏输入，不清空控制器；切回支持类型可恢复草稿，最终保存时按账户能力归一化字段。
- 编辑账户切换类型时同样保留暂时隐藏的卡片/信用草稿；最终保存为不支持能力的类型时才清空对应持久化字段。
- 已有关联退款的支出不能改变交易类型，页面直接展示只读类型行，不弹出只有一个选项的菜单。
- 菜单叶子仍先完成关闭动画，再执行页面状态回调或平台图片选择。

## 明确保留 Bottom Sheet / Picker / Dialog

- 账户分组、标签筛选：用户可动态新增，标签筛选还包含快捷项与分区。
- 账单日、还款日、预算周期起始日：均为 28–29 项长列表。
- 账户、分类、货币、标签、图标：首页指标等领域长列表或分组列表。
- 旧账本币种确认、预算单期覆盖、导入来源与映射：属于多步骤或带说明流程。
- 应用锁方式：虽然只有两项，但属于安全设置，需要带说明的聚焦式 Sheet。
- 日期、时间、金额、文本、退款编辑和危险操作：继续使用专用 Picker、输入 Sheet 或确认 Dialog。
- 已持续展示全部选项且属于高频切换的 `SegmentedButton` / `ChoiceChip` 不隐藏进菜单。

## 验收

- `showOptionSheet` 页面调用从 25 处缩减为 7 处，剩余调用全部属于上面的保留范围。
- 静态选择显示当前值与勾选状态；禁用项、菜单外关闭、返回和深层动画继续由通用组件测试覆盖。
- 页面测试覆盖设置与备份保存边界、AI 协议、交易筛选、收支类型、曲线序列、账户类型草稿、交易退款锁定和个人资料性别。
- 执行 `dart format .`、`flutter analyze` 与全量 `flutter test`。
- Android 真机补充验证小屏上下避让、深浅色、中英文、TalkBack，以及拍照/相册菜单关闭后正常拉起系统入口。
