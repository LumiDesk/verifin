# Veri Fin 产品文档

本文描述当前产品边界与核心体验。逐项验收见 `docs/acceptance-checklist.md`，工程架构见 `CLAUDE.md`，数据与技术取舍见 `docs/dev/tech-decisions.md`。

## 产品定位

Veri Fin 是一款完全免费、数据自主、本地优先的 Android 记账应用。它不要求账号，不依赖自有服务端，不投放广告，也不接入广告或统计遥测 SDK。权威账目数据保存在用户设备；只有用户主动启用导出、WebDAV 备份或 AI 功能时，相关数据才会发送到用户选择的目标。

产品目标是提供一套可长期使用的个人记账、资产、预算和分析工具，同时保持数据可导出、功能可离线运行、关键操作由用户确认。

## 产品原则

- **本地优先**：账本、账户、交易、分类、标签、附件、周期规则和预算以本地 SQLite 为权威数据源。
- **用户控制**：编辑与设置先形成草稿，由用户明确保存；返回时可以保存、不保存或继续编辑。导入、恢复、初始化、删除和 AI 记账等高影响操作必须经过预览或确认；AI 与外部采集入口绝不静默落账。
- **隐私优先**：应用不监听通知、屏幕、无障碍或短信。截图在端上 OCR，原图不上传；使用远程 AI 时只把必要文本或账目摘要发往用户配置的端点。
- **可迁移**：支持手动/自动备份、本地目录、加密、WebDAV 和旧备份兼容，避免数据被锁在应用中。
- **Android 优先**：当前只交付 Android，所有文件、权限、通知、小组件、分享与安装能力都必须有真实原生实现。

## 信息架构

底部导航固定为四个 Tab：

- **首页**：可配置概览卡、快速记账、最近交易、预算提醒和日历入口。
- **资产**：净资产、账户类型/自定义分组、信用账户、余额趋势和账户报告。
- **看板**：预算执行、分类/标签统计、趋势、月度结构、统计分析和 AI 账目问答。
- **我的**：个人资料、账本/分类/标签管理、周期记账、设置、数据管理和系统工具。

## 核心流程

### 记账

首页「记一笔」支持三种行为：手动记账、AI 记账、点击手动/长按 AI。手动入口先打开支持四则运算的数字键盘，再进入记账详情页；详情页支持支出、收入、转账、金额、分类、标签、账户/无账户、转入账户、手续费、备注、日期时间和图片附件。

默认付款账户按账本保存。记账自动识别会根据用户自己的历史推断支出/收入类型、分类、标签和备注，可在设置中全局关闭；AI 草稿和导入草稿不启用自动识别。

AI 记账、截图识账、系统分享和自动化 Intent 都只生成草稿。截图文字在本机离线识别，识别文本再交给用户配置的 OpenAI 兼容端点；用户必须在记账页确认保存。

### 多币种与离线汇率

每个账本有一个本位币，预算、首页、看板、统计和 AI 汇总统一使用该币种；每个账户只持有一种账户币种，余额、初始余额、额度和手续费始终按账户币种计算。普通交易分别保存原币金额、账户真实扣入账金额和记账时冻结的本位币金额，跨币转账保存转出、转入两端的实际金额。账户或账本存在财务数据后币种锁定，旧账本只允许一次「数字不变、重新确认币种」的重解释。

汇率按账本、外币和生效日保存在 SQLite，方向固定为 `1 外币 = X 本位币`，只使用交易日或更早的最近记录。应用不会联网下载或后台刷新汇率；修改或删除汇率不重算已保存交易，只影响以后录入、周期补记和资产估值。缺少必要汇率时不按 1:1 猜测：交易要求补齐实际金额或汇率，资产总额则显示缺率状态而不是部分和。

金额单位默认使用符号后置（如 `100 ¥`），也可在设置中切换为代码前置（如 `CNY 100`）。单币种账本默认隐藏每个金额旁重复的单位，首页概览、预算、日历、看板和统计页在页头或卡片标题中统一标明单位；多币种账本的账户与交易金额始终保留单位。界面汇率使用可读的自适应小数位，只缩短展示，不降低保存或导出精度。

### 交易、报销与退款

交易列表支持日期分组、搜索、多维筛选、排序和批量改分类/账户/删除。转账只影响账户余额，不计入收支统计，手续费由转出账户承担。

支出可标记待报销。退款是挂在原支出上的独立关联条目，支持多笔、跨账户、待到账/已到账、发起与到账日期和备注；只有已到账退款影响余额与支出净额。交易详情把本体、退款和附件作为一个草稿，点击右上角保存后原子提交；放弃时三者都不变化。退款明细在原支出和「待退款」清单中管理，当前不进入通用交易时间线，也暂未提供退款自身的附件编辑入口。

### 预算与分析

预算支持默认月预算、总预算与分类预算的单期覆盖、分类默认预算、按日花销上限，以及每账本独立的预算周期起始日。`BudgetOverviewPage` 用于查看当前/历史预算状态，并管理所选月份/周期的总预算和分类预算覆盖；`BudgetSettingsPage` 集中编辑默认值、周期和分类默认预算。只有预算体系按自定义周期聚合，统计报表仍按自然月。

首页概览卡可配置多个指标和趋势序列。看板提供预算、分类、标签、日趋势与月度结构；统计分析支持月/年/自定义范围、支出/收入、同比环比和分类下钻。所有数据图表都应支持点按或滑动查看具体值。

AI 账目问答以只读财务 Agent 运行：Agent 可通过原生 Tool Calls 或兼容标记协议自主查询当前活动账本，并以统计卡、柱状图、折线图、可点击交易列表、表格和 Markdown 作答；聊天页会展示可展开的工具调用步骤，但不展示模型推理、原始工具 JSON 或底层异常。聊天文本、已完成步骤与序列化结果卡片保存在设备本地，不进备份；AI 工具不能修改任何数据。

### 资产与信用账户

账户可按类型或自定义分组展示，并支持账户币种、计入资产、隐藏、排序、图标、完整卡号/后四位和账户备注。账户行保留原币余额，净资产和历史走势完整折算到当前账本本位币；缺任一必要汇率时不显示不完整总额。资产页普通展开/折叠只影响本次浏览；视图模式、背景和排序集中在「资产显示设置」中明确保存。账户类型包括网络支付、信用账户、信用卡、储蓄卡、投资账户和现金。

信用卡与信用账户支持额度、账单日、还款日、已用/可用额度、本期账单与还款。还款本质是一笔使用转账分类的转账；扣款账户可为空表示他人代还。余额调整通过生成差额交易表达，不直接覆盖历史流水。

## 数据、备份与安全

### 存储分层

- SQLite：账本及本位币、交易三层金额、账户及币种、按日汇率、账户分组、分类、标签、附件、周期规则、月度/分类/按日预算。
- SharedPreferences/KV：主题、语言、触感、页面配置、资产排序、默认账户、预算周期、自动识别开关、AI/备份/提醒/应用锁等偏好。
- Controller 内存集合是运行时读取源，但真实平台不能以内存实现代替持久化。

SQLite repository 的 `saveX` 对外保持“传入集合即最终表状态”的语义；生产实现对主要账目表做行级差分写入。附件与小型预算表可整表覆盖；交易详情通过单个事务原子保存交易/退款和附件，导入、恢复、重置和删账本等多表操作使用原子整替。

### 备份格式与范围

未加密备份为 zip：`backup.json` 加独立的 `attachments/<id>` 文件；加密备份为 AES-GCM + PBKDF2 保护的 JSON 信封。导入可自动识别 zip、加密信封和旧版明文 JSON。

JSON v2 备份包含账本本位币和确认状态、账户币种、交易各端金额和转换来源、周期汇率策略、汇率表、全部既有账目数据与显示偏好；v1 旧备份继续兼容，数字原样载入为待用户确认的 CNY。应用锁哈希、备份口令、WebDAV/AI 凭证、语言、提醒、备份目录、日志和 AI 聊天历史等保持设备本地，不进入备份。

第三方账单导入支持支付宝、微信、薄荷、一木、钱迹、Tally 和本应用 CSV 模板。用户先选择来源，解析后进入零副作用预览，可排除/编辑交易并映射账户、分类、标签，确认后才落库。本应用 CSV 导出保留原币、账户/转入账户币种、两端实际金额、本位币金额和派生汇率；外币缺率可在预览前手工补齐，导入汇率默认不写汇率表，只有用户明确开启后才随最终保留的交易保存。

### 应用安全

应用锁支持 6 位 PIN、3×3 图案和系统生物识别。锁配置只保存加盐哈希，不保存明文密码或生物特征；启用应用锁后使用 `FLAG_SECURE` 隐藏截图和最近任务缩略图。

本地日志只保存在设备，用户可查看、复制或清除；应用不做远程崩溃或行为遥测。

## Android 系统能力

- 系统下拉快捷磁贴打开快速记账。
- 系统分享图片/文本和显式 `CAPTURE_TEXT` Intent 进入待确认识账流程。
- 今日支出、预算、资产总额三个桌面小组件，并支持应用内请求固定。
- 每日记账提醒、本地通知测试和回前台重排。
- Android SAF 备份目录、系统 Downloads 导出和文件导入。
- GitHub flavor 的应用内更新支持锁屏断网/超时后的 APK 断点续传与进程重启恢复，完整后校验 Release 长度、可选 SHA-256、包名和版本；Play flavor 由商店负责更新并移除相关安装权限。

平台能力必须覆盖冷启动、回前台、进程被杀、重启/升级、权限拒绝和 Doze 等场景。正式验收使用 GitHub CI 生成的 release APK；本机 APK 不作为交付依据。

## 视觉与国际化

界面方向是紧凑型移动端金融工具：较高信息密度、小圆角、轻阴影、统一 Header 和 4/8pt 间距节奏。主交互色为 `#346edb`，辅助蓝为 `#3498db`，青绿色只用于收入和正向状态；金额为零显示中性色 `0`，不出现 `-0`。

应用支持跟随系统、简体中文和 English。用户可见文案通过 Flutter gen-l10n 管理；系统日期/时间选择器、通知、小组件和生物识别提示都应跟随应用语言。种子账本和分类按首次创建时的语言生成，之后属于用户数据，不随语言切换自动改名。

## 当前边界

- 不提供账号体系、实时云同步或多端协作；WebDAV 只用于用户主动配置的备份/恢复。
- 不提供在线汇率、后台行情刷新、加密货币、自定义商品货币或汇兑损益核算；法币目录与汇率操作均离线。
- 不做通知监听、无障碍监听、短信读取或后台静默记账。
- 暂无项目、商家和债务/借贷管理；无法忠实表达的第三方债务记录不会导入。
- GitHub 自分发 APK 只提供 arm64-v8a；极老 32 位设备无法安装。Google Play 使用 AAB 按设备分发。
- 当前不提供 Unsplash API 搜索图库，只支持内置线上图、自定义链接和本地图片。

## 技术结构

- `lib/main.dart`：初始化与根生命周期。
- `lib/app/veri_fin_controller*.dart` + `VeriFinScope`：单一应用状态源。
- `lib/pages/`：页面与交互流程。
- `lib/data/`：SQLite schema、迁移和 repository。
- `lib/local_storage/`：设备偏好 KV。
- `lib/app/backup/`、`lib/app/ai/`、`lib/app/reminder/`、`lib/app/logging/`：领域子系统。
- `android/`：MethodChannel、SAF、更新、分享、通知、小组件和双 flavor 配置。

开发命令、组件复用、测试、文档和发布规则见根目录 `AGENTS.md`。
