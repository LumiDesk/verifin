# Veri Fin 验收清单

## 当前能力
- 首页支持快速记账、最近交易、收支统计入口、预算设置和日历日期交易入口。
- 预算「预算」总览页支持月份切换、月预算状态标签（沿用默认/本期单独，点按调本期覆盖）、近 6 月趋势、上月历史对比、最近 12 个月历史汇总、支出进度、剩余额度、剩余日均、分类预算排序和状态提示、分类预算树默认折叠；点分类行主体可修改/清除所选月或期的单期覆盖，分类行不显示独立预算数字，有子分类时仅在行尾垂直居中显示展开/收起箭头；右上角齿轮进「预算设置」页配置默认月预算（每月自动沿用）、按日预算上限、预算周期起始日与分类默认预算。
- 交易支持本地保存、刷新保留、详情查看、编辑保存和删除确认；交易详情的本体、退款和附件共用一个草稿并原子保存。
- 普通全屏编辑/设置页统一在右上角使用软碟保存图标；快速记账页例外使用底部固定“保存”主按钮。修改字段、开关、选择项或排序只改变页面草稿，返回时统一询问“保存 / 不保存 / 取消”。
- 资产页默认按账户类型展示，支持账户管理、分组管理、展开折叠、账户详情和账户报告；视图模式、资产卡片背景、分区排序和分区内账户排序集中到独立「资产显示设置」页，保存后一起生效。
- 新用户和初始化后默认无资产账户（首启动引导完成时必定创建首个账户）；切换账本后账户和分组按账本隔离。
- 多币种：新手引导/新建账本选择本位币，账户选择账户币种；旧账本可一次确认或原值重解释币种，已有财务数据后账本/账户币种锁定。「我的 → 数据与工具 → 货币与汇率」可离线维护按日汇率历史，页头问号按需展示汇率说明。
- 普通交易保存原币、账户实际金额和冻结本位币金额；跨币转账保存两端实际金额，退款和周期记账支持跨币换算。预算、首页、看板、统计、AI 与小组件使用本位币，账户余额保留账户币种，资产缺率时不显示部分总额。金额单位可选符号后置/代码前置；单币种账本可隐藏单位（默认开启），开启后金额旁、页头与卡片角标、AI 回答都不再标出币种，关闭后恢复。
- 账户详情支持余额调整，按差额生成“余额调整”交易记录；余额允许为负（信用卡、贷款类账户的常态），目标值为负时确认框说明负余额表示欠款。
- 账户类型含「信用账户」（网络支付与信用卡之间），用于花呗/白条等；信用卡/储蓄卡可填完整卡号与后四位，后四位默认跟随完整卡号（可关掉手填），列表只显示后四位、详情页可复制完整卡号。
- 信用卡/信用账户可设信用额度，详情页展示已用/可用额度、使用进度条与本期账单，资产列表显示可用额度；「还款」入口预填欠款、可选扣款账户或「无账户」代还，确认后按转账抵消欠款、不计入收支统计。
- 隐藏账户集中在资产页底部入口和独立隐藏账户页面中展示。
- 图片入口使用统一裁剪页：头像为 1:1，资产背景为与净资产卡片一致的宽幅封面比例。
- 看板页基于本地交易数据展示近 7 日统计、资产汇总、本月收支、预算执行、分类·标签排行与日趋势，年统计再给本年收支、12 个月收入/支出双柱、收支热力与整年排行。
- 看板月统计 / 年统计顶部有期间栏：默认本月 / 今年，可步进或从弹层选择月份 / 年份；范围下界是首笔记账、上界是当前月 / 年，到边界时箭头禁用且不提供未来期间；切换期间后摘要与排行等面板按所选期间刷新（日趋势在本月用累积展开窗口、历史月份用整月窗口；预算执行按所选月的预算周期），非本月 / 今年时提供「本月 / 今年」回跳；期间不写账目、不进备份。
- 首页和看板底部提供“n个面板”入口，面板管理页支持开关面板与排序模式拖动调整顺序，点击软碟保存后持久化并随备份导出/导入。
- 我的页支持个人资料编辑、账本管理和设置入口，不展示本地数据/云同步状态卡片。
- 个人信息页已设置的生日可从行尾清除；保存后再次进入或重启仍为“不设置”，放弃草稿则保留原生日。
- 分类管理支持按支出、收入、转账维护分类，并能新增、重命名、更换图标；多级分类按深度缩进，有子分类时显示行尾垂直居中的旋转展开箭头，叶子分类不显示展开控件；排序进入独立模式，点击软碟后一次提交。标签和账户分组排序遵循同一规则。**分类与标签跟随账本**：列表只显示当前账本的分类/标签，笔数只算当前账本，改名、换图标、移动、合并、删除与排序都只作用当前账本；新建账本自带一份内置默认分类，切换账本后分类与标签随账本切换。
- 设置页支持主题选择器、触感反馈开关、手动检查 GitHub Release 更新、版本展示，以及「关于」组里的鸣谢名单（真实头像或本地生成头像 + 常显称呼 + 在爱发电支持入口）；设置字段先改草稿，点击软碟保存后统一应用。
- 设置 → 外观 → 导航栏样式进入独立选择页：每个样式展示真实预览与名称说明，当前样式带选中标记；点选只改设置页草稿，设置页保存后才生效并持久化，不保存退出则丢弃；导航样式只存在本机、随备份导入不改变当前设备选择。切换样式后当前 Tab 与页面滚动位置不丢，四个目的地与返回键语义不变。
- 可选「液态玻璃」底栏：由本地 vendor 的 `GlassTabBar.bottom` 实现，浮动胶囊（高 60、左右 12、底部留白 24）真实采样底栏后方页面内容并做玻璃模糊/折射；支持点击与拖动切换、松手吸附和按压反馈；浅/深色、360/393dp 下不溢出，四个标签常显、读屏能念出选中项；着色器不可用时库自行降级且交互不缺；`extendBody` 下页面内容从胶囊下方滚过、列表末项不被遮挡，记账按钮抬到胶囊之上（含系统安全区）。停靠底栏保持不透明实色与原有几何不变。
- 我的页「数据管理」入口进入数据管理页，集中手动/自动备份、导入恢复、第三方账单导入和初始化数据；未加密备份为 zip（`backup.json` + 独立附件），加密备份为流式加密容器（`.verifin`），旧版明文 JSON 与旧版 JSON 加密信封仍可导入。
- 备份、导出、恢复、WebDAV 上传/下载全过程显示阶段进度与百分比，可中途取消；写入后用流式 SHA-256 校验，写坏或文件损坏给出明确提示而不是闪退。图片附件改为独立文件存储，冷启动不再把全部图片读进内存；升级后后台自动整理历史内嵌图片，可中断并会在下次启动继续，完成后回收旧库腾出的空间。「从文件恢复」经系统文件选择器流式读取，选完文件后应正常导入，不再出现 `No content provider` 类失败。
- 数据管理页可选择备份目录（Android 弹系统文档树授权、桌面弹目录选择），「立即备份」写入该目录并更新「上次备份时间」；可清除目录授权。
- 选择备份目录后出现自动备份设置：频率（仅手动/每次打开/每次记账后/每隔 N 小时）、间隔与保留份数；自动备份在打开、回前台或记账后按频率触发，超出保留份数的旧自动备份被清理。
- 备份加密：设置密钥后导出/备份文件为密文，导入加密文件需正确密钥（已存密钥自动尝试、失败可手动输入且可重试）；清除密钥需确认，旧加密文件仍需原密钥。
- CSV 模板导入/导出：可下载模板并导出当前账本交易；多币种列保留原币、账户/转入账户币种、账户金额、转入金额、本位币金额和派生汇率；退款作为独立行保留原支出编号、待到账/已到账、发起与到账日期、到账账户及三层金额。缺率行可在预览前批量手填汇率，未解决行明确列出并排除；导入汇率默认不保存，用户开启后只保存最终纳入交易使用的汇率。表头严格白名单校验，第三方软件各走独立入口。
- WebDAV：可填写地址/账号/密码并「测试连接」，手动「上传到 WebDAV」，「从 WebDAV 恢复」能列出远端备份并选择恢复（加密文件走解密流程）；开启自动上传后随自动备份一并上传。
- Android 端支持系统下拉快捷开关“快速记账”，点击后进入应用并打开快速记账数字键盘。
- Android 端使用持久化本地存储，应用从后台划掉后重新进入仍应保留交易、资产和设置。
- 启动先渲染启动壳再载入数据：偏好、数据库、控制器、周期补记分阶段执行，单阶段过慢时显示当前阶段、已等待时长与「重试」；数据库打不开时沿用「数据可能还在，别清数据」的说明。存储就绪前的错误会在日志里补回。
- 桌面组件、快捷磁贴与记账按钮共用单飞入口：重复触发复用已经打开的数字键盘或编辑页，不叠加第二层。
- 软件日志可展开单条记录的堆栈并单独复制；框架错误附带上下文与信息收集器，便于把反馈定位到具体 Widget。
- Android Manifest 明确禁用系统 Auto Backup；未主动使用应用内导出/WebDAV 时，SQLite 账目和 SharedPreferences 凭据不得进入系统云备份。
- 长列表、可搜索或需分区的选择器使用底部弹层；短枚举与轻量单选使用锚点菜单；破坏性操作使用确认弹窗。
- 截图识账 / 采集记账：截图或账单文本经本机离线 OCR + 用户自配 AI 解析成草稿，确认后才落账；应用本体不监听任何通知或屏幕。三个入口——App 内相册选图、系统分享图片/文本、自动化 Intent（`top.talyra42.verifin.action.CAPTURE_TEXT`）。
- 标签、图片附件和多级分类：交易可带多个账本内标签和本地压缩图片；分类支持任意层级树、emoji 图标、父子移动和参照自愈。
- 退款使用关联条目模型，支持多笔、跨账户、待到账/已到账、双日期和备注；交易详情里的退款随父交易和附件统一保存，只有已到账退款影响余额与净额；待退款页核销是独立明确命令，退款不进入通用交易时间线，当前也没有退款自身的附件编辑入口。已有部分退款时，新增默认剩余金额（非整数）保存成功且按币种精度落库。
- 看板页提供只读 AI 财务 Agent：Composer 的账本选择器可选择本次对话使用的账本，默认当前账本；切换账本不影响应用全局活动账本，且已有对话保留。Agent 通过原生 Tool Calls 或兼容协议查询所选账本，以图表、统计卡、表格、Markdown 和不可点击的交易列表作答；聊天中可展开查看工具调用步骤。对话只保留在当前页面，离开后重进不恢复；清空当前对话位于 Header 设置按钮左侧，无对话时保留同宽占位，设置按钮位置固定。未配置 AI 时显示空状态插画和前往配置入口，不展示重复的能力说明段。已配置 AI 时聊天页右上角提供设置入口，点击进入 AI 设置页。
- AI 设置提供 8 个内置 OpenAI-compatible 渠道（DeepSeek、火山方舟、Kimi、智谱 GLM、阿里云百炼、OpenAI、OpenRouter、Ollama）和自定义渠道；预设 Base URL 只读，切换渠道清空旧 Key/模型，API Key 可留空，模型可远端获取或手动填写。渠道与模型选择器使用可搜索、可分组的统一底部弹层。连接参数使用可见描边输入框；工具调用协议同样以只读输入框呈现，收起时只显示当前选项，点击后展开带说明的选择菜单。聊天页与 AI 设置页不重复展示本地存储、可选性或检测请求的说明段。
- 应用锁支持 PIN/图案/生物识别并启用 `FLAG_SECURE`；锁屏页提供「忘记密码」找回路径（两步破坏性确认后清空本地账目并关闭应用锁，同时关闭生物识别）；启用锁时外部分享/自动化 Intent 与小组件路由要等解锁后再消费，桌面小组件配置页也必须先验证且验证前不读取账本名称或真实预览；设置页提供每日记账提醒、测试通知、软件日志和桌面小组件入口。
- push 到 `main` 会触发质量 CI（格式 + analyze + test + 统一设计专项 + 不交付的 debug APK 编译门禁）；`vX.Y.Z` 标签会构建 GitHub arm64 release APK 与 Play AAB，并创建待真机验收的预发布。`integration_test/` 不在 CI 跑，需在真机或本地模拟器手动执行。

## 验收重点
- 首次引导中文默认预选 CNY、英文默认预选 USD，用户可在建首个账户前修改；新建账本必须显示本位币。空账本可改本位币，已有交易、非零余额/额度、预算、周期规则或汇率后必须锁定并引导新建账本。
- v13→v14 数据库升级后所有旧数字、余额、预算和排序不变，账本标记待确认；确认 CNY 或一次重解释为其他法币后数值仍不变且不能重复重解释（当前 schema 为 v19）。新库 schema、每个历史版本迁移矩阵、模型/仓储往返必须通过。
- 同币交易保持原有简洁流程；外币收支应能分别核对原币、账户实际金额和本位币金额，缺汇率/金额时不能保存。修改或删除汇率不得改变已保存交易、退款净额和历史报表。
- 跨币转账应按 `accountAmount` 扣转出账户、按 `toAccountAmount` 加转入账户，手续费只按转出账户币种扣除且不计普通收支；跨币退款只有到账后才按实际账户金额影响余额、按冻结本位币金额冲减原支出。
- 无账户转账切换转入账户且币种变化时，必须提供“按汇率换算”和“保留数字重新解释”两种明确选择；缺汇率时不得猜 1:1，也不得静默改变金额。
- 账户列表在多币种时显示账户原币；总资产与走势完整折算成本位币，任一必要汇率缺失时显示缺率状态而不是 0 或部分和；原币余额为 0 的账户不需要汇率，也不能让历史走势因空外币账户整块消失；非零账户只有部分月份缺率时，走势保留可估值月份并在缺率月份显示断点和具体缺失月份/币种。账户详情与账户报告的余额走势纵轴按账户币种判断零值和精度（KWD `0.001` 不得显示为 0），账户报告页头不得用单一本位币单位概括账户原币余额。预算/首页概览/日历/看板/统计/AI 汇总在**多币种账本**（或关闭了「单币种隐藏单位」）时必须在页头或卡片标明本位币单位，单币种账本 + 默认开关下这些位置都不标；桌面小组件金额遵循同一显示偏好。多币种时符号/代码样式应跟随设置，单币种默认隐藏重复单位且可关闭该行为。
- 界面中常见汇率最多显示 4 位小数，极小值可自适应放宽到 6–8 位；用户输入、SQLite 与 CSV 往返仍保留最高 10 位小数精度。汇率列表与历史记录显示带年份的生效日期；历史记录保留来源且不逐条标过期；手工修改导入汇率后来源显示为手动维护。
- JPY/KWD 等非两位币种在快速记账、预算、余额调整、额度和聚合报表中遵循 ISO minor unit；JPY 禁用金额小数点，KWD 的 `0.001` 不得显示或判断为 0。
- 汇率方向全应用恒为 `1 外币 = X 本位币`，只使用目标日期或更早的最近记录，不使用未来记录；允许预录未来生效汇率，但必须标“未生效”且不得用于今天或更早日期的估值。超过 30 个日历日的当前有效汇率可提示过期，但不得联网刷新或静默回退 1:1。
- 已保存的手工/导入外币交易只改日期、备注、分类或标签时三层金额保持冻结；改原币金额时按既有结算比例缩放。换算区展示实际采用的汇率生效日，资产页展示估值最旧汇率。
- JSON v4/zip/加密备份应往返本位币、账户币种、交易三层金额、周期策略、汇率表、**按账本保存的分类与标签**与图片附件；v1/v2/v3 旧备份仍可导入（数字解释为待确认 CNY，全局分类/标签按账本各展开一份），内嵌 base64 图片流式转成文件。非法币种、负数/非有限金额、错误或重复汇率必须在覆盖现有数据前整体拒绝。
- 本应用 CSV 导出后重新导入应保留普通跨币消费与跨币转账的账户币种/两端实际金额；同名不同币种账户不得误合并。导入预览取消、排除、补率和「保存导入汇率」开关在确认前都不得落库。
- 外币退款导入与本应用 CSV 重导入必须直接生成原币、到账账户币种和本位币正确的关联退款；多笔退款、待到账退款、跨账户/跨币种到账和不同发起/到账日期都必须保留，排除原支出时不得留下悬空退款。退款只在 `settledAt` 改变账户与资产趋势，仍冲减原支出统计月份。

- AI 设置的「检测能力」应分别验证普通补全、流式响应和原生 Tool Calls，并显示实际协议；自动模式在原生工具不受支持时应自动使用兼容模式，手动固定协议时不得静默改用另一种协议。
- AI 渠道选择应展示 8 个预设及自定义入口，宫格含 Logo、名称与说明，搜索可跨分组；选中预设后 Base URL 只读，切到自定义后可编辑并可选填模型列表地址。切换渠道只改设置页草稿并清空上一渠道 Key/模型，取消不落盘。

- 浅色和深色模式下，首页、资产、看板、我的四个 Tab 不应出现白屏、文本重叠或明显低对比内容。

- 多账本隔离：只在 A 账本用过的分类/标签不影响 B 账本的删除与编辑；在两个账本里给同一概念的分类可以各自改名、换图标、改层级并独立排序；删除账本会连带删掉该账本的分类与标签，其它账本不受影响。**真机必验**：升级后（v18 → v19）各账本看到的分类/标签集合与升级前一致，交易、周期规则与分类预算的引用都仍指向本账本的对应项。
- 数据管理页导出数据后，应下载备份文件（未加密为 zip、加密为 `.verifin` 容器）；Android 端默认写入系统下载目录，并在成功提示中说明位置。**真机必验**：带图片附件时导出未加密备份 → 初始化 → 导入该备份 → 附件应完整还原（验证 zip 打包/解包在 Android SAF/下载路径上的往返）。
- 设置页点击检查更新后，应打开弹窗查询 GitHub Release；弹窗展示当前版本、最新版本和状态。无更新提示当前已是最新，有更新时展示“下载新版本”按钮，下载期间展示进度，下载完成后自动打开系统安装确认。下载期间点击遮罩或 Android 系统返回键不得关闭弹窗、不得产生第二个下载任务；Activity 重建后的原生锁仍须阻止并发任务。锁屏断网、读取超时或连接中断后应自动尝试 HTTP Range 续传；多次失败时保留断点，弹窗保持目标版本号、展示已下载比例与“继续下载”，关闭弹窗、重新检查或进程重启后仍可续传。服务器忽略 Range 时允许安全地从零覆盖半成品；半成品绝不能进入安装器。安装包必须在 Release 长度、可选 SHA-256、包名与版本校验完成后才可原子提交。**下载完成后主按钮应变为“立即安装”**：在系统安装页点取消/返回再回到弹窗，点“立即安装”应复用已下载的安装包重新拉起安装器；关闭弹窗后再次检查同一版本也应恢复“立即安装”，不重新下载（缓存被系统清理或校验失败时回退为重新下载）。
- 设置页底部应展示当前版本；不展示“同步方式”和“Android 打包”说明卡片。
- 记账提醒（我的 → 设置 → 记账提醒，**Android release 真机验**）：点“发送测试通知”应立刻在通知栏出现一条；开启每日提醒并设一个 2–3 分钟后的时间，锁屏等待到点应弹出（改用精确闹钟，休眠/后台下也应触发）。国产 ROM（小米/华为/OPPO/vivo 等）若仍收不到，属系统后台限制，需在系统里允许通知并加入省电/自启动白名单——说明文案应提示这点。
- 快速记账数字键盘默认应触发系统触感反馈，刚安装进入程序时也应生效；关闭设置页“触感反馈”后不再触发。
- 数据管理页导入数据前必须二次确认，确认后应能恢复交易、账户、账本、预算、个人信息和主题偏好。
- 导入空文件或错误格式文件时，应显示失败提示，不应清空当前数据。
- 初始化数据入口必须使用红色危险样式；初始化前必须双重确认，确认后交易、账户、账本、预算、个人信息和主题偏好恢复默认。
- push 到 `main` 会触发质量 CI（格式 + analyze + test + 统一设计专项 + 不交付的 debug APK 编译门禁）；只有推送 `vX.Y.Z` 标签后，GitHub CI 才创建**预发布**并附加 Android APK。APK 文件名应为 `verifin-vX.Y.Z-arm64-短提交号.apk` 形式，本地开发机不作为 Android 交付打包环境。
- 连续 GitHub Release APK 应使用同一签名，除切换到稳定签名的首次迁移外，后续版本应可覆盖安装。
- 截图识账 / 采集记账（**Android release APK 必验**，因端上 OCR 依赖 ML Kit，release 的 R8 混淆行为与 debug 不同，只有 release 包能暴露真实问题）：
  - 前置：先在「我的 → 设置 → AI 设置」配好可用 AI 端点并「检测能力」通过；未配置时触发任一识账入口应弹引导框跳去 AI 设置页，不崩、不落账。
  - App 内截图识账：首页底栏圆形记账按钮 → AI 记账弹层 →「截图识账」→ 相册选一张账单截图 → 弹不可点穿的「识别中」模态 → 本机 OCR → AI 解析 → push 记账页并预填金额/类型/分类/账户/时间；确认才落账，返回不产生任何账目。**（务必真机复验能正常 OCR 出中文。）**
  - 系统分享图片：在别的 App（支付宝/微信/相册）把账单**图片**分享给 Veri Fin → 同样 OCR→解析→确认页；图片不上传、识别完即弃、不落库留存。外部 `content://` 流须边读边累计，超过 25 MB 立即拒绝，不能完整读入后才检查。
  - 系统分享文本：把账单**文本**分享给 Veri Fin → 直接 AI 解析→确认页。
  - 自动化 Intent：用 `docs/product/automation.md` 的 adb 命令（或 Tasker）发 `top.talyra42.verifin.action.CAPTURE_TEXT`（extra `text`）→ App 被拉起直接进识别→草稿→确认页；**冷启动（App 未运行时发）与运行中（已在前台）两种都应正确弹出**。
  - 边界与容错：纯风景图（无文字）应提示「没识别到文字」；聊天/网页图（有文字非交易）应提示「未识别到交易」；无数字文本不应白调 AI；AI 报错/超时应弹本地化错误提示——以上全部不崩、不落账。
  - 隐私红线：以上任何路径**没在确认页点保存就绝不出现在账本里**（AI 只产草稿，永不静默落账）；用本地模型时数据不出设备；App 未申请通知监听/无障碍/短信权限。

- 「关于」组里的「鸣谢」应列出包内名单（真实头像或本地生成头像 + 常显称呼），分组为空时不出现组标题；底部「在爱发电支持 Veri Fin」必须跳系统默认浏览器打开捐赠页，浏览器不可用时给出错误轻提示，不得静默失败或崩溃。
- 未提供真实头像时，同一称呼在任何主题、任何版本下必须生成同一张头像（图形与色相由 `SHA1(称呼)` 决定，另加同色相的淡彩圆底保证深浅主题下都可读）；提供真实头像时按包内资源显示。改动生成头像算法必须同步更新 `test/credits_test.dart` 的 SVG 指纹快照。

## 当前不作为完成标准
- 登录账号、实时云同步和多端协作；WebDAV 仅作为用户自配的备份/恢复通道。
- 把本地开发机构建的 APK 当作交付物；正式验收以 GitHub CI 生成的 release APK 为准。
- 项目、商家、债务/借贷管理，以及无法忠实表达的第三方债务记录导入。
- 在线汇率、加密货币/商品货币、外汇持仓成本与汇兑损益；当前只支持离线维护的 ISO 4217 法定货币。
- 通知监听、无障碍监听、短信读取或后台静默记账。
- Unsplash API 搜索图库；当前只使用预设线上图片、自定义图片链接和本地图片。

功能演进优先级不在本清单维护；本文件只记录当前能力与验收边界。

## Android 真机开发与交付

- 使用 CI 固定 Flutter 版本；缺失工具先自动安装并复检，步骤见 [Android 开发](../dev/android-development.md)。
- 独立 diagnostic applicationId 运行正式入口，首次启动、四个根页、菜单、快速记账与冷启动可用。
- CI release/R8 包覆盖安装后保留已有账目、账户、预算和设备偏好；禁止清数据或卸载正式应用。
- 卡片、快捷按钮、菜单、弹层与默认停靠底栏均为不透明实色，无背景模糊、无渐变、无 Shader 滤镜；浅/深色下层次靠表面色差、描边和阴影区分。唯一例外是可选的液态玻璃底栏（见本节导航项）。
- 用户开始验收前清理本任务的测试应用。

## 统一排版验收

遵循 [统一设计与交互规范](../design/design-system.md)。393×852 与 360dp、浅/深色均验证；预算结构、概览指标方块及右侧胶囊、我的四列宫格不变。底栏点击、页面滑动、菜单与弹层进出、滚动末项避让逐项检查。正式发布前另做 Android 真机手势与帧时间验收。

统一排版验收覆盖四个根页面与设置、交易、预算、分类、标签、数据管理页，包含 360/393dp 浅深色；宫格标题不得小于说明。底栏逐项检查：四个中文标签常显、选中项换填充图标并随主题主色、点击后底栏动画与页面过渡同起同落、切页途中点击或滑动页面后底栏仍与当前页一致、底部留白不贴屏幕下边缘、读屏能念出当前选中的 Tab。
