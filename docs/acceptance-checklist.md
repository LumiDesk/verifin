# Veri Fin 验收清单

## 当前已完成
- 首页支持快速记账、最近交易、收支统计入口、预算设置和日历日期交易入口。
- 预算「预算」总览页支持月份切换、月预算状态标签（沿用默认/本月单独，点按调本月覆盖）、近 6 月趋势、上月历史对比、最近 12 个月历史汇总、支出进度、剩余额度、剩余日均、分类预算排序和状态提示、分类预算树默认折叠；点分类行主体可修改/清除所选月或期的单期覆盖，父分类左侧箭头只展开/收起；右上角齿轮进「预算设置」页配置默认月预算（每月自动沿用）、按日预算上限、预算周期起始日与分类默认预算。
- 交易支持本地保存、刷新保留、详情查看、编辑保存和删除确认；交易详情的本体、退款和附件共用一个草稿并原子保存。
- 普通全屏编辑/设置页统一在右上角使用软碟保存图标；快速记账页例外使用底部固定“保存”主按钮。修改字段、开关、选择项或排序只改变页面草稿，返回时统一询问“保存 / 不保存 / 取消”。
- 资产页默认按账户类型展示，支持账户管理、分组管理、临时展开折叠、账户详情和账户报告；视图模式、资产卡片背景、分区排序和分区内账户排序集中到独立「资产显示设置」页，保存后一起生效。
- 新用户和初始化后默认无资产账户；切换账本后账户和分组按账本隔离。
- 多币种已落地：新手引导/新建账本选择本位币，账户选择账户币种；旧账本可一次确认或原值重解释币种，已有财务数据后账本/账户币种锁定。「我的 → 数据与工具 → 货币与汇率」可离线维护按日汇率历史。
- 普通交易保存原币、账户实际金额和冻结本位币金额；跨币转账保存两端实际金额，退款和周期记账支持跨币换算。预算、首页、看板、统计、AI 与小组件使用本位币，账户余额保留账户币种，资产缺率时不显示部分总额。金额单位可选符号后置/代码前置，单币种账本可隐藏重复单位。
- 账户详情支持余额调整，按差额生成“余额调整”交易记录。
- 账户类型含「信用账户」（网络支付与信用卡之间），用于花呗/白条等；信用卡/储蓄卡可填完整卡号与后四位，后四位默认跟随完整卡号（可关掉手填），列表只显示后四位、详情页可复制完整卡号。
- 信用卡/信用账户可设信用额度，详情页展示已用/可用额度、使用进度条与本期账单，资产列表显示可用额度；「还款」入口预填欠款、可选扣款账户或「无账户」代还，确认后按转账抵消欠款、不计入收支统计。
- 隐藏账户集中在资产页底部入口和独立隐藏账户页面中展示。
- 图片入口使用统一裁剪页：头像为 1:1，资产背景为与净资产卡片一致的宽幅封面比例。
- 看板页基于本地交易数据展示预算执行、分类、排行、7 天趋势和带纵轴的月度结构。
- 首页和看板底部提供“n个面板”入口，面板管理页支持开关面板与排序模式拖动调整顺序，点击软碟保存后持久化并随备份导出/导入。
- 我的页支持个人资料编辑、账本管理和设置入口，不展示本地数据/云同步状态卡片。
- 分类管理支持按支出、收入、转账维护分类，并能新增、重命名、更换图标；排序进入独立模式，点击软碟后一次提交。标签和账户分组排序遵循同一规则。
- 设置页支持主题选择器、触感反馈开关、手动检查 GitHub Release 更新和版本展示；设置字段先改草稿，点击软碟保存后统一应用。
- 我的页「数据管理」入口进入数据管理页，集中手动/自动备份、导入恢复、第三方账单导入和初始化数据；未加密备份为 zip（`backup.json` + 独立附件），加密备份为 JSON 信封，旧版明文 JSON 仍可导入。
- 数据管理页可选择备份目录（Android 弹系统文档树授权、桌面弹目录选择），「立即备份」写入该目录并更新「上次备份时间」；可清除目录授权。
- 选择备份目录后出现自动备份设置：频率（仅手动/每次打开/每次记账后/每隔 N 小时）、间隔与保留份数；自动备份在打开、回前台或记账后按频率触发，超出保留份数的旧自动备份被清理。
- 备份加密：设置密钥后导出/备份文件为密文，导入加密文件需正确密钥（已存密钥自动尝试、失败可手动输入且可重试）；清除密钥需确认，旧加密文件仍需原密钥。
- CSV 模板导入/导出：可下载模板并导出当前账本交易；多币种列保留原币、账户/转入账户币种、账户金额、转入金额、本位币金额和派生汇率。缺率行可在预览前批量手填汇率，未解决行明确列出并排除；导入汇率默认不保存，用户开启后只保存最终纳入交易使用的汇率。表头严格白名单校验，第三方软件各走独立入口。
- WebDAV：可填写地址/账号/密码并「测试连接」，手动「上传到 WebDAV」，「从 WebDAV 恢复」能列出远端备份并选择恢复（加密文件走解密流程）；开启自动上传后随自动备份一并上传。
- Android 端支持系统下拉快捷开关“快速记账”，点击后进入应用并打开快速记账数字键盘。
- Android 端使用持久化本地存储，应用从后台划掉后重新进入仍应保留交易、资产和设置。
- Android Manifest 明确禁用系统 Auto Backup；未主动使用应用内导出/WebDAV 时，SQLite 账目和 SharedPreferences 凭据不得进入系统云备份。
- 选择器统一使用底部弹出样式，破坏性操作使用确认弹窗。
- 截图识账 / 采集记账（1.8.7 起）：截图或账单文本经本机离线 OCR + 用户自配 AI 解析成草稿，确认后才落账；应用本体不监听任何通知或屏幕。三个入口——App 内相册选图、系统分享图片/文本、自动化 Intent（`top.talyra42.verifin.action.CAPTURE_TEXT`）。
- 标签、图片附件和多级分类已落地：交易可带多个全局标签和本地压缩图片；分类支持任意层级树、emoji 图标、父子移动和参照自愈。
- 退款使用关联条目模型，支持多笔、跨账户、待到账/已到账、双日期和备注；交易详情里的退款随父交易和附件统一保存，只有已到账退款影响余额与净额；待退款页核销是独立明确命令，退款不进入通用交易时间线，当前也没有退款自身的附件编辑入口。
- 看板页提供只读 AI 财务 Agent：Agent 通过原生 Tool Calls 或兼容协议自主查询当前活动账本，以图表、统计卡、表格、Markdown 和可点击交易列表作答；聊天中可展开查看工具调用步骤，文本、已完成步骤与结果卡片仅存设备本地，重开可还原。
- 应用锁支持 PIN/图案/生物识别并启用 `FLAG_SECURE`；设置页提供每日记账提醒、测试通知、软件日志和桌面小组件入口。
- PR 与 push 到 `main` 会运行格式/analyze/test，并构建不交付的 `github` debug APK 作为 Kotlin/Manifest/原生桥编译门禁；`vX.Y.Z` 标签会构建 GitHub arm64 release APK 与 Play AAB，并创建待真机验收的预发布。

## 验收重点
- 首次引导中文默认预选 CNY、英文默认预选 USD，用户可在建首个账户前修改；新建账本必须显示本位币。空账本可改本位币，已有交易、非零余额/额度、预算、周期规则或汇率后必须锁定并引导新建账本。
- v13 数据库升级后所有旧数字、余额、预算和排序不变，账本标记待确认；确认 CNY 或一次重解释为其他法币后数值仍不变且不能重复重解释。新库 schema、每个历史版本迁移矩阵、模型/仓储往返必须通过。
- 同币交易保持原有简洁流程；外币收支应能分别核对原币、账户实际金额和本位币金额，缺汇率/金额时不能保存。修改或删除汇率不得改变已保存交易、退款净额和历史报表。
- 跨币转账应按 `accountAmount` 扣转出账户、按 `toAccountAmount` 加转入账户，手续费只按转出账户币种扣除且不计普通收支；跨币退款只有到账后才按实际账户金额影响余额、按冻结本位币金额冲减原支出。
- 账户列表在多币种时显示账户原币；总资产与走势完整折算成本位币，任一必要汇率缺失时显示缺率状态而不是 0 或部分和。预算/首页概览/日历/看板/统计/AI 汇总必须在页头或卡片标明本位币单位；桌面小组件金额遵循同一显示偏好。多币种时符号/代码样式应跟随设置，单币种默认隐藏重复单位且可关闭该行为。
- 界面中常见汇率最多显示 4 位小数，极小值可自适应放宽到 6–8 位；用户输入、SQLite 与 CSV 往返仍保留最高 10 位小数精度。
- JPY/KWD 等非两位币种在快速记账、预算、余额调整、额度和聚合报表中遵循 ISO minor unit；JPY 禁用金额小数点，KWD 的 `0.001` 不得显示或判断为 0。
- 汇率方向全应用恒为 `1 外币 = X 本位币`，只使用目标日期或更早的最近记录，不使用未来记录；超过 30 个日历日可提示过期，但不得联网刷新或静默回退 1:1。
- 已保存的手工/导入外币交易只改日期、备注、分类或标签时三层金额保持冻结；改原币金额时按既有结算比例缩放。换算区展示实际采用的汇率生效日，资产页展示估值最旧汇率。
- JSON v2/zip/加密备份应往返本位币、账户币种、交易三层金额、周期策略与汇率表；v1 备份导入为待确认 CNY。非法币种、负数/非有限金额、错误或重复汇率必须在覆盖现有数据前整体拒绝。
- 本应用 CSV 导出后重新导入应保留普通跨币消费与跨币转账的账户币种/两端实际金额；同名不同币种账户不得误合并。导入预览取消、排除、补率和「保存导入汇率」开关在确认前都不得落库。
- 外币退款导入与本应用 CSV 重导入必须直接生成原币、到账账户币种和本位币正确的关联退款；排除原支出时不得留下悬空退款。退款只在 `settledAt` 改变账户与资产趋势，仍冲减原支出统计月份。
- 到期周期规则缺率时首页显示待处理币种并可进入处理；补率后由用户明确触发立即补记。汇率、预算、账户、账本切换和历史交易编辑后桌面小组件应及时刷新。
- 除快速记账页外，普通全屏编辑页右上角应使用软碟保存图标和“保存”tooltip，不用对勾表达保存；快速记账页使用无顶部分割线的底部固定主按钮。未修改或校验未通过时按钮禁用。
- 编辑页修改后点击 Header 返回、Android 系统返回或预测性返回，都应只出现一个“保存 / 不保存 / 取消”对话框：保存成功退出，不保存丢弃草稿，取消继续编辑；保存失败必须留页且草稿不丢。未修改或改回原值时直接退出。
- 删除、初始化、导入、立即备份、还款、余额调整、待退款核销和应用锁等明确命令在自身确认后立即执行；即使父页另有未保存草稿，命令完成后也不得再次弹未保存提示或把已删除实体保存回来。
- AI 设置的「检测能力」应分别验证普通补全、流式响应和原生 Tool Calls，并显示实际协议；自动模式在原生工具不受支持时应自动使用兼容模式，手动固定协议时不得静默改用另一种协议。
- AI Agent 调用工具时应出现可展开的进行中 / 完成 / 失败 / 重试步骤，最终答复正常流式显示；原始工具 JSON、兼容协议标记、模型推理文本和 `HttpException` 等底层异常不得出现在聊天气泡中。中断时保留已收到的正文并提供「重新回答」，且不得重复执行已经完成的工具。
- 浅色和深色模式下，首页、资产、看板、我的四个 Tab 不应出现白屏、文本重叠或明显低对比内容。
- 首页卡片标题使用统一字号和字重，信息密度应接近“日历”卡片。
- 首页概览趋势图应按累积展开窗口展示（1 号起，按 7 天步进到当月）；收支统计详情页顶部可切换周/月/季/年视图（周·月·季按天描点、年按 12 个月描点），前后翻页按当前档位步进，x 轴日期稀疏显示（每 5 天一个），滑动仍能看到具体某天/某月。
- 收支统计详情页下方每日记录可点击，点进即当天的交易明细。
- 首页概览卡可自定义：点进收支统计页右上角「编辑」，可分别设置大数字、结余位、三个小卡片各展示什么数据（本月/今日/本周/本年/总/资产/报销等），设置曲线画支出/收入/结余，改卡片标题（留空显示「概览」），并可一键恢复默认；保存前只更新预览，点击软碟后生效并持久化。
- 首页概览趋势图不应额外出现浅色背景框。
- 预算页修改月份预算后，首页预算卡应同步展示新的预算金额和剩余状态；修改分类单期预算后，对应分类行应立即展示预算金额和进度，清除覆盖后应回落分类默认预算（无默认时回到未设置），且不得影响同月其它分类或其它账本；临近或超支分类应排在前面。
- 分类预算达到 85% 或已超支时，首页预算卡应展示最需要关注的分类提醒；正常状态不展示额外提醒。
- 预算页历史对比应展示本月支出、上月支出和预算使用率变化；分类预算行应展示上月同分类支出。
- 预算页近 6 月趋势应展示支出柱、预算线、月份标签和纵轴刻度；预算历史页应展示最近 12 个月汇总并可点击月份进入对应预算页。
- 看板页顶部应展示预算执行摘要，包括本月预算、本月支出、分类预算数量和超支分类数量。
- 看板日趋势应与首页概览使用一致的累积展开窗口。
- 面板管理页关闭某个面板或调整顺序时，父页面在保存前不得改变；点击软碟保存后按新配置展示，重启仍保留；只剩一个开启面板时继续关闭应提示并保持开启。
- 面板管理页右上角“恢复默认”应先弹出确认框，确认后只更新草稿；仍需点击软碟保存才提交，取消或离页选择“不保存”保持原配置。
- 资产页设置背景图后，展开/折叠账户分区时净资产背景图不应闪烁；选择本地图片确认裁剪时应显示加载对话框，完成后自动关闭。
- 看板分类圆环和月度收支图不应出现文本重叠；分类统计圆环应横向居中，分类名称通过同色引线从圆环指出，不在右侧放最高分类说明；分类统计应展示金额最高的 5 个分类，剩余分类合并为“其他”；月度收支图应显示纵轴刻度。
- 快速记账流程应完整闭环：FAB 输入金额、进入详情、点底部保存后首页出现记录。页面顶部使用紧凑支出/收入/转账切换；常用分类按三列胶囊展示，子分类不常驻展开，选中父分类右下角的省略号进入现有多级选择器；日期、时间、标签、待报销、附件和币种集中在“更多信息”标签区。标签可多选并现场新建，附件可连续添加多张、横向预览并逐张删除。
- 快速记账数字键盘普通按钮使用统一弱背景，不显示蓝色边框；浅色模式为浅底深字，深色模式为深底浅字，`OK` 可点击时使用主蓝色背景和白色文字，不可点击时有清晰的浅蓝灰禁用态。
- 浅色模式下快速记账数字键盘应为浅色按钮和深色数字，不应出现黑底黑字。
- 首页按系统返回键时应先提示“再次返回退出程序”，短时间内再次返回才退出。
- 日期和时间选择器应显示中文界面。
- 交易详情页应支持修改金额、类型、分类、账户、备注、日期、时间、退款和附件；保存前 Controller/SQLite 不变化，点击软碟后本体、退款和附件一次提交。添加已到账退款后保存，报销徽标、筛选、首页指标和净支出应立即正确，重启前后一致（issue #31）。
- 交易详情页备注输入应为单行文本。
- 交易列表应支持关键词搜索，并可按账户和分类筛选；无匹配结果时应显示明确空状态。
- 交易列表批量改账户只展示对全部选中交易都安全的同账户币种目标；混合币种、无账户、悬空账户或转账目标冲突时提示逐笔编辑，不修改任何 `accountAmount/baseAmount/fee`。
- 交易列表搜索下方的“全部账户/全部分类”筛选项应靠左排列，不应被左右分散。
- 交易明细列表应分批加载：往下滚动时随滚动无缝追加下一批（快到底部前就已备好，不停在底部等待）；顶部“N 笔交易 / 收支合计”按完整数据统计、不随滚动变化；多选“全选”应选中全部符合筛选的交易而非仅当前可见批次；切换筛选后列表从头刷新。
- 转账交易应同时影响转出和转入账户余额，不应计入收入或支出统计；账户详情应能展示相关转账。
- 从日历点击日期进入交易列表后，应默认筛选当天，同时仍可切换到全部时间等普通筛选。
- 账户详情页应支持修改类型、名称、图标、单行备注、分组、计入资产、隐藏状态和卡片信息，点击软碟后一次保存；余额调整、还款、隐藏/删除账户是独立明确命令，不等待页面保存。
- 添加账户时输入银行或支付平台名称，应自动匹配对应账户图标；信用卡和储蓄卡填写卡号后四位后，资产列表账户名后展示灰色后四位标记。
- 添加账户和账户详情的账户图标选择器应展示通用图标和本地 SVG 图标，列表行左侧为图标、右侧为描述。
- 调整账户余额后，最近交易和首页交易列表应出现对应“余额调整”记录。
- 删除或隐藏账户后，快速记账详情页的账户选择中不应再出现该账户。
- 资产页默认净资产卡片无背景图时，应使用普通卡片背景，不使用蓝色渐变；趋势图应位于资产/负债摘要下方并有足够高度。
- 设置资产背景图后，净资产卡片只能使用轻量黑色可读性遮罩，不应出现蓝色品牌渐变遮罩。
- 资产页没有账户时应展示居中的空状态，提示用户从右上角添加资产。
- 账户分组页没有分组时应展示空状态，提示用户点击右上角加号创建分组。分组行只显示固定文件夹符号、名称和账户数；点击行或三点须打开同一个锚点菜单，仅提供重命名与删除。
- 资产页默认展示类型视图；切换到分类视图后，未选择分组的账户应展示在“未分组”卡片中，不能因为 `groupId` 为空而丢失。
- 资产页右上角资产操作菜单应提供「资产显示设置」入口；分类/类型视图在该设置页切换，保存前资产页不变化，保存后刷新仍保留。
- 资产页每个账户分区应支持点击标题展开/折叠；折叠属于本次浏览状态，不持久化，重新进入页面恢复展开。
- 资产页账户分区展开/折叠应有短动画；开启触感反馈时，展开/折叠也应触发轻触感。
- 资产页分区右侧总额不应统计“不计入资产”的账户。
- 「资产显示设置」应允许通过手柄调整分区顺序，并在展开分区内长按调整账户顺序；退出选择“不保存”时顺序不变，点击软碟保存后按账本、视图和分区持久化；开启触感反馈时拖动有轻触感。
- 点击资产卡片右上角图片图标后应进入「资产显示设置」，可选择线上图、自定义链接、本地图片和清除背景；选择/裁剪后仍是草稿，点击软碟才应用。
- 本地图片裁剪页应能调节缩放、水平位置和垂直位置，确认后显示裁剪结果。
- 资产背景和头像裁剪页在 Android 真机上不应黑屏，确认后应展示实际裁剪结果。
- Android 端本地图片选择、头像裁剪、备份导入和备份导出应在真机上真实可用（未加密 zip、加密 JSON 信封、旧版明文 JSON 兼容）。
- 头像编辑应复用同一裁剪页，保存后个人页展示新头像。
- 分类管理页新增分类后，应立即出现在记账详情页和全部分类选择器中。
- 分类、标签和账户分组管理页只有进入排序模式后才显示拖动手柄；拖动不即时落库，取消/不保存保持原顺序，点击软碟后相关选择器按新顺序展示且重启保留。删除非空账户分组前须明确提示账户将移到“未分组”，不删除账户或交易。
- 已有交易使用的分类不能删除，应提示使用笔数；未使用分类删除前必须二次确认。
- 数据管理页导出数据后，应下载备份文件（未加密为 zip、加密为 json）；Android 端默认写入系统下载目录，并在成功提示中说明位置。**真机必验**：带图片附件时导出未加密备份 → 初始化 → 导入该备份 → 附件应完整还原（验证 zip 打包/解包在 Android SAF/下载路径上的往返）。
- 设置页点击检查更新后，应打开弹窗查询 GitHub Release；弹窗展示当前版本、最新版本和状态。无更新提示当前已是最新，有更新时展示“下载新版本”按钮，下载期间展示进度，下载完成后自动打开系统安装确认。下载期间点击遮罩或 Android 系统返回键不得关闭弹窗、不得产生第二个下载任务；Activity 重建后的原生锁仍须阻止并发任务。锁屏断网、读取超时或连接中断后应自动尝试 HTTP Range 续传；多次失败时保留断点，弹窗保持目标版本号、展示已下载比例与“继续下载”，关闭弹窗、重新检查或进程重启后仍可续传。服务器忽略 Range 时允许安全地从零覆盖半成品；半成品绝不能进入安装器。安装包必须在 Release 长度、可选 SHA-256、包名与版本校验完成后才可原子提交。**下载完成后主按钮应变为“立即安装”**：在系统安装页点取消/返回再回到弹窗，点“立即安装”应复用已下载的安装包重新拉起安装器；关闭弹窗后再次检查同一版本也应恢复“立即安装”，不重新下载（缓存被系统清理或校验失败时回退为重新下载）。
- 设置页底部应展示当前版本；不展示“同步方式”和“Android 打包”说明卡片。
- 记账提醒（我的 → 设置 → 记账提醒，**Android release 真机验**）：点“发送测试通知”应立刻在通知栏出现一条；开启每日提醒并设一个 2–3 分钟后的时间，锁屏等待到点应弹出（改用精确闹钟，休眠/后台下也应触发）。国产 ROM（小米/华为/OPPO/vivo 等）若仍收不到，属系统后台限制，需在系统里允许通知并加入省电/自启动白名单——说明文案应提示这点。
- 快速记账数字键盘默认应触发系统触感反馈，刚安装进入程序时也应生效；关闭设置页“触感反馈”后不再触发。
- 数据管理页导入数据前必须二次确认，确认后应能恢复交易、账户、账本、预算、个人信息和主题偏好。
- 导入空文件或错误格式文件时，应显示失败提示，不应清空当前数据。
- 初始化数据入口必须使用红色危险样式；初始化前必须双重确认，确认后交易、账户、账本、预算、个人信息和主题偏好恢复默认。
- 普通提交和 `main` 推送不应触发 GitHub Actions；只有推送 `vX.Y.Z` 标签后，GitHub CI 才创建 Release 并附加 Android APK。APK 文件名应符合 `verifin-v1.0.0-短提交号.apk` 形式，本机不作为 Android 交付打包环境。
- 连续 GitHub Release APK 应使用同一签名，除切换到稳定签名的首次迁移外，后续版本应可覆盖安装。
- 截图识账 / 采集记账（**Android release APK 必验**，因端上 OCR 依赖 ML Kit，release 的 R8 混淆行为与 debug 不同，只有 release 包能暴露真实问题）：
  - 前置：先在「我的 → 设置 → AI 设置」配好可用 AI 端点并「检测能力」通过；未配置时触发任一识账入口应弹引导框跳去 AI 设置页，不崩、不落账。
  - App 内截图识账：首页 FAB → AI 记账弹层 →「截图识账」→ 相册选一张账单截图 → 弹不可点穿的「识别中」模态 → 本机 OCR → AI 解析 → push 记账页并预填金额/类型/分类/账户/时间；确认才落账，返回不产生任何账目。**（这是 1.8.7 曾报 NPE、1.8.8 修复的路径，务必真机复验能正常 OCR 出中文。）**
  - 系统分享图片：在别的 App（支付宝/微信/相册）把账单**图片**分享给 Veri Fin → 同样 OCR→解析→确认页；图片不上传、识别完即弃、不落库留存。外部 `content://` 流须边读边累计，超过 25 MB 立即拒绝，不能完整读入后才检查。
  - 系统分享文本：把账单**文本**分享给 Veri Fin → 直接 AI 解析→确认页。
  - 自动化 Intent：用 `docs/automation.md` 的 adb 命令（或 Tasker）发 `top.talyra42.verifin.action.CAPTURE_TEXT`（extra `text`）→ App 被拉起直接进识别→草稿→确认页；**冷启动（App 未运行时发）与运行中（已在前台）两种都应正确弹出**。
  - 边界与容错：纯风景图（无文字）应提示「没识别到文字」；聊天/网页图（有文字非交易）应提示「未识别到交易」；无数字文本不应白调 AI；AI 报错/超时应弹本地化错误提示——以上全部不崩、不落账。
  - 隐私红线：以上任何路径**没在确认页点保存就绝不出现在账本里**（AI 只产草稿，永不静默落账）；用本地模型时数据不出设备；App 未申请通知监听/无障碍/短信权限。

## 当前不作为完成标准
- 登录账号、实时云同步和多端协作；WebDAV 仅作为用户自配的备份/恢复通道。
- 本机 APK 作为交付物；正式验收以 GitHub CI 生成的 release APK 为准。
- 项目、商家、债务/借贷管理，以及无法忠实表达的第三方债务记录导入。
- 在线汇率、加密货币/商品货币、外汇持仓成本与汇兑损益；当前只支持离线维护的 ISO 4217 法定货币。
- 通知监听、无障碍监听、短信读取或后台静默记账。
- Unsplash API 搜索图库；当前只使用预设线上图片、自定义图片链接和本地图片。

功能演进优先级不在本清单维护；本文件只记录当前已实现能力与验收边界。
