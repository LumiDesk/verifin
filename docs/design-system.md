# Veri Fin 统一设计与交互规范

2026-09-05 Android 玻璃修复：旧方向高光的逐段模糊已在 REDMI K90 Pro Max（Android 17）独立复现 GPU 分配失败及 Vulkan 0x14 崩溃；连续透明度网格替换后，Flutter 3.47.2 release/R8 已完成该机开启、保存、冷启动、切页、深浅色及关闭验收，真实导航 Shader 集成测试通过。Android 恢复高级材质，默认关闭，旧 KV 保留；其他平台仍保护。不能据此断言所有 GPU 均已验证。CI 固定 Flutter 3.47.2，升级引擎须重做真机验收；正式包仍由 CI 构建，须用户明确授权发版，禁止要求清除应用数据。

本文件是后续页面、组件和材质修改的统一入口。以用户已确认的约定为准；研究稿只解释背景，不能用旧实验方案覆盖这里的布局。更新规则时同步本文件、组件注册表及相关测试。

## 生效范围

正式应用仅以 Android 交付，真机调试使用同一套真实页面、Controller、组件和持久化逻辑。独立 diagnostic applicationId 隔离数据；不再维护 Web 预览。

候选外观仍由 `UNIFIED_DESIGN_PREVIEW` 控制，内容玻璃还需 `GLASS_DESIGN_PREVIEW`。用户于 2026-09-05 授权发布 minor 版本真机体验：从 v1.16.0 开始，CI 的 APK/AAB 编译门禁均显式开启上述两个参数。无参数开发构建暂保留旧路径用于回归；本地复现手机外观须传同样参数。候选方案的共享排版现覆盖全部页面：公共页面骨架、标题、卡片默认使用同一套紧凑参数，独立记账编辑页同步 16dp 页边距；图表、表单和弹层的业务专用占位仍按内容保留。

## 已确认的布局

| 项目 | 约定 |
| --- | --- |
| 普通页面页边距 / Header | 横向 16dp / 高度 56dp |
| 公共内容卡片 | 圆角 16dp；内边距横向 14dp、纵向 **12dp**；显式 padding 优先 |
| 概览 | 主金额 32sp；右侧摘要胶囊靠卡片右边，左侧金额区域 Expanded；保留三个有底色的指标方块 |
| 趋势 / 最近交易 | 趋势高度 96dp；首页显示三笔，可进入完整列表；标题无鼠标 hover 底色，保留点击、焦点与导航 |
| 预算 | **保持原始结构**：左支出、中间剩余及比例、右剩余日均、底部预算总额；中央占位 132dp，圆环画布 116dp |
| 我的 | 工具入口保持四列宫格，长文案和大字号不得溢出；不改成列表 |
| 信息密度 | 通过间距和排版优化，不能删除业务指标、原有方块或改变预算结构 |

页面继续使用 `Scaffold > SafeArea > VeriPage` 与 `VeriHeader` / `PageHeader`。默认页面和固定页脚的头部对齐规则见 [页面骨架](ui-guidelines.md)。颜色、字号和圆角使用主题令牌，不在各页复制样式。

## 字体层级

字号必须保持语义层级。2026-09-05 真机反馈后撤回统一设计对全局字体的放大，恢复 v1.15.17 基线：displayLarge 38、displayMedium 32、displaySmall 26、titleLarge/Medium/Small 17/14/13、bodyLarge/Medium/Small 14/13/12、labelLarge/Medium/Small 12/11/10sp，页面标题 w800。我的宫格标题仍使用 bodyMedium 13sp / w600，副标题使用 labelSmall 10sp / w400；首页主金额和导航标签保留局部明确尺寸（32/12sp），不能为调整单处而放大所有页面字体。字体家族及系统 textScaler 不变。

## 两档材质

在 v1.16.0 发布包及玻璃预览构建的“设置 → 通用”中提供 **高级材质**，默认关闭。修改后点击保存才生效，取消保留原选择。普通构建没有此候选材质入口，避免出现无效设置。

| 状态 | 内容表面与圆环 | 底部导航 |
| --- | --- | --- |
| 关闭 | 中性半透明填色、真实背景模糊；预算圆环始终使用原来的常规渐变环 | 普通磨砂轨道和滑块；不创建透镜组件、不加载折射程序 |
| 开启 | 在基础材质上增加柔和方向高光；预算圆环不参与玻璃效果 | 按压/拖动时使用当前帧图标/文字的 ImageFiltered Shader；静止/松手停用过滤，按压膨胀、拖动改变方向光 |
| 高对比度 | 内容表面不透明，停用模糊与方向高光；预算用清晰常规圆环 | 不进入高级透镜路径 |

高级高光沿曲面法线衰减：左上、右下较亮，右上、左下消隐；不能画成整圈纯白线。静态细高光峰值浅色 0.46、深色 0.22；外侧柔光为峰值的 20%，交互只小幅增强。深色主题必须独立校准，不能照搬浅色亮度。

用户于 2026-09-05 要求撤回预算环玻璃效果：恢复原常规 SweepGradient 进度环，保留预算颜色、比例、布局和无接缝处理，不再保留 glass/advanced 绘制分支。正文、金额和卡片图标不模糊。导航只过滤自己的图标与文字，不采样账目或写出图片；关闭高级材质会卸载 Shader。

内容卡片复用 `VeriGlassSurface`，同页不重叠区域共享 BackdropGroup；菜单、弹层使用独立过滤。用户资产封面保持原内容。应用锁显示时下层账目 Offstage 并排除焦点，禁止透出私密内容。

每个页面路由必须拥有自己的不透明背景，并随路由一起进入、退出与预测性返回；不能只在 Navigator 外绘制背景再让所有页面透明。全局 Material surface 保持不透明，半透明只在具体玻璃组件内指定。玻璃列表关闭越界拉伸；表面过滤使用 src 混合。导航已撤回截图/异步读回流程，使用同帧 ImageFilter.shader，跨 Tab 高亮阈值不得卸载过滤层；不支持 Shader filter 的后端保留实时内容与普通形变。

深色输入框默认无白色描边，以柔和填色区分；聚焦用品牌蓝细边，错误用错误色。菜单深色遮罩为 12%，面板使用提亮的中性灰基色与 72% 染色，避免接近纯黑，同时照顾亮背景上的文字对比度；不以父级 Opacity 包裹整块模糊表面，保留缩放和真实背景模糊。底部弹层在玻璃染色层内提供透明 Material，保证 ListTile 的反馈绘制可见。

菜单进出为 220ms 对称缓入缓出：表面染色、阴影、光照与模糊强度独立渐变，文字/图标在过滤器内部淡出，缩放仅 0.96–1。禁止只缩放后直接卸载，也不能重新把整个 BackdropFilter 包进 Opacity。系统减少动态效果开启时直接切换。

设置分组：外观（主题、高级材质）、金额显示（两位小数、单位样式、单币种隐藏单位）、通用（语言、触感、应用锁）、记账（记一笔动作、默认账户、自动识别、AI 设置）、关于。各组仍共用页面草稿与保存操作，分组不能变成即时写入。

此处的用户选择机制取代此前“不考虑帧率/功耗”的阶段性实验要求。开关关闭的路径必须真实省去高级渲染工作，不能只隐藏效果。

## 导航与输入

- 四个根目的地使用同一浮动胶囊；首页才显示快捷记账按钮，其他页面胶囊居中。中性选中状态，不给整条导航染品牌蓝。
- 保留连续指针状态机：2dp 开始拖动、按住追随、松手吸附、取消回到原目的地；跨页动画只认最终目的地。高级效果不得改变命中区域或阻断点击。
- 系统安全区之外保留导航左右及底部 24dp；列表末项按实际底栏高度避让。内容延伸到导航背后，不能添加整宽底栏底色。
- 最近交易等分区标题的 hover、按压 highlight 和 splash 均不绘制横条，保留点击与键盘焦点。高级动效尊重系统减少动画设置。
- 单选、确认框、输入和底部弹窗复用公共入口；金额使用数字键盘。保存失败要保留草稿并反馈，不能误报成功。短反馈统一用根级 Feedback Host。

## 偏好与开发边界

高级材质使用设备 KV `verifin.advanced_material.v1`，默认 false，全局不分账本，不进账目备份，恢复备份和初始化账目都保留当前设备选择。Controller 完成落盘后才更新独立 `ValueNotifier`；根组件注入 `VeriMaterialScope`，绘制组件不直接访问 Controller/KV。

账目仍以 Android 本机 SQLite 为权威；本地优先、AI 只生成待确认草稿、Android 原生能力必须真实可用。完整工程和业务不变量仍以 [AGENTS.md](../AGENTS.md) 与 [技术决策](dev/tech-decisions.md) 为准。

## 修改与验收

先查 [组件注册表](dev/components.md)，复用后再扩展。新增可见文案完成中英文 l10n；不为材质调整改动金额、预算或退款口径。按独立功能提交，不积压工作区，不擅自推送或发版。

widget 布局测试使用 **393×852**，补充 360dp、大字号、浅/深色和高对比度测试。实际检查保存/取消/冷启动、导航点击/拖动/取消、菜单、键盘和滚动末项；材质开关开、关都验证。运行 format、analyze、相关测试与全量测试。Android 手势、系统安全区及真实流畅度仍需真机验证，桌面截图不替代它。
