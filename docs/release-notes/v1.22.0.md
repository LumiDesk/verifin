## 本版变化

- 图片识账改为把图片直接发送给你自己配置的视觉模型：AI 记账弹层「图片识账」→ 相册选图 → 识别 → 直接进入记账页；不再经过端上 OCR，也没有第二次「解析」或额外的图片预览页。
- AI 设置页的「检测能力」同时检查图片输入能力；检测成功后以独立的「能力检测结果」卡片展示连接、流式输出、原生 Tool Calls、实际协议和图片识别状态。
- 移除 ML Kit 端上 OCR 及对应依赖、原生库和 R8 规则，安装包体积减小。
- 隐私政策同步说明：图片会发送到你配置的 AI 端点，图片识账本身不保存图片（除非你手动添加为附件）。

## 升级说明

请下载 APK 直接覆盖安装，**不要卸载旧版本或清除应用数据**。换机或重装前请先在「数据管理」导出备份。
