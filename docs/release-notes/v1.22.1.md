## 本版变化

- 交易明细的排序与日期分组改为两个独立选项：金额排序也能按日期分组，或关掉分组按金额顺序平铺（每行显示日期）；日期升序时分组顺序同步反转。
- 交易列表、交易详情、记账页，以及退款、周期规则等处的日期在跨年时显示年份，本年仍只显示月日。
- AI 记账与图片识账的分类识别更准：可以按分类名匹配已有分类（含子分类路径、全角/半角与空格差异），认不出时优先放进「未分类」并提示确认。
- 看板「分类 · 标签排行」点进分类后的交易列表只显示当前所选月份 / 年份的交易，不再混入全部历史。

相关 Issue：[#82](https://github.com/LumiDesk/verifin/issues/82)。

## 升级说明

请下载 APK 直接覆盖安装，**不要卸载旧版本或清除应用数据**。换机或重装前请先在「数据管理」导出备份。
